## 1. 四种拍卖形式与收益等价定理（RET）

### 1.1 四种形式

| 形式 | 谁定价格轨迹 | 均衡出价 | 关键策略点 |
|---|---|---|---|
| 英式（升价） | 买方递增叫价 | 私人价值下停在真实估值 | 可观察对手动作、可跳价发信号 |
| 荷式（降价） | 卖方从高往低 | **与首价密封同构（策略等价）** | 抢在他人之前喊停，无法观察对手 |
| 首价密封 | 一次盲投 | $b^*(v)=\frac{N-1}{N}v$（均匀分布） | 需"压价"（shading），收益与胜率权衡 |
| 次价密封 | 一次盲投 | $b(v)=v$（**弱占优**） | 如实出价，无需猜人数 |

- "次价如实出价是占优策略"最早由 Vickrey 提出；首价两买家均匀分布下均衡出价 = 估值一半。 【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]
- **荷式与首价策略等价** ⇒ 游戏里**一套出价函数可驱动两种界面**，不必写两套 AI。 【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]
- **报价即信号**：关联价值下英式公开叫价会泄露信息；Milgrom–Weber 的**关联性原则**指出卖者披露更多信息通常提高期望收益。 【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]

### 1.2 RET 成立的四条基准假设

1. 投标人**风险中性**；2. 各自**独立**抽取的**私人价值**（IPV）；3. 信息**对称**；4. 支付**仅是出价的函数**（无外部性/转售/预算约束）。

在此之上，任何满足 (a) 总是分配给最高估值者、(b) 零估值者零剩余的机制，卖者**期望收益相同**。 【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]

> ⚠ 关键推论：首价那个 $(N-1)/N$ **不是启发式**，它正是让首价与次价"收益等价"的那个出价水平。 【学术共识】

### 1.3 RET 失效条件（**对设计最重要**）

| 放松的假设 | 结果 |
|---|---|
| 风险厌恶 | **首价 > 英式/次价**（风险厌恶者更愿抬价换胜率） |
| 关联/共同价值 | 出现赢家诅咒；通常英式升价收益更高 |
| 非对称投标人 | 收益排序改变，等价失效 |
| 预算约束 | 次价均衡策略改变，一/二价期望收益不再相等 |
| 佣金/激励支付、转售 | 收益函数被改写，等价失效 |

【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]

> **设计含义**：想让"四种形式真的不一样"，只需让 NPC 的**风险厌恶参数不同**或引入**共同价值成分** —— 收益等价自然被打破。
> **这正是"性格差异化"能产生玩法深度的理论基础。** 【设计建议】

## 2. 六个关键现象（可直接变成玩法）

### 2.1 赢家诅咒（Winner's Curse）
共同价值下，中标 = 你比所有人更乐观地高估 ⇒ **胜出本身是坏消息**，系统性超额支付。
经典实验：Kagel & Levin (1986), AER。 【学术共识】[来源: https://en.wikipedia.org/wiki/Winner%27s_curse]
反制：机制需给"信号最高者"保留信息租金，否则低估者永不出价。 【学术共识】[来源: https://economics.mit.edu/sites/default/files/2022-10/countering+the+winners+curse.pdf]

### 2.2 抬价托（Shill Bidding）
卖方/同伙投**虚假出价**抬价。 【学术共识】[来源: https://link.springer.com/chapter/10.1007/978-3-030-03991-2_19]
**可编码的识别特征**（= 玩家能抓到的破绽）：
- 托价常集中在拍卖**早期** 【某篇观点】[来源: https://ccsenet.org/journal/index.php/cis/article/download/45734/25809]
- `ShillScore` 类评分（时机 + 频率 + 与卖方历史关联）可识别，且已扩展到**多卖方合谋** 【学术共识（方法论文）】[来源: https://arxiv.org/pdf/1812.10868]
- 线索：反复与中标者"擦肩"、只抬价从不真赢、成交后与卖方强关联

### 2.3 合谋围标
`tacit collusion`（默契合谋）说明**合谋不必明文串通**，重复博弈下可自发形成。 【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]

### 2.4 跳跃式加价（Jump Bidding）
动机 A：**成本信号**（示强吓退）；动机 B：**不耐烦/交易成本**（减少轮次）。
副作用：可能**降低卖方收益**。 【学术共识 + 某篇观点】[来源: http://neumann.hec.ca/pages/nicolas.sahuguet/signalling.pdf]

### 2.5 狙击（Sniping）与结束规则
- 平台明确允许狙击（含自动狙击软件），但"允许"≠"保证获胜" 【平台规则】[来源: https://www.ebay.co.uk/help/buying/auctions-bidding/bid-sniping?id=4224]
- **软关闭（soft close）显著减少狙击** —— 延长时间让对手能回应 【某篇观点（田野实验）】
- ⇒ **结束规则是"狙击能否成为可选策略"的开关，低成本高杠杆** 【设计建议】

### 2.6 报价即信号
跳价是**显式**信号；更一般地，投标人的行为会影响他人估值（关联价值），故"报价"承载共同价值信息。 【学术共识】

## 3. 出价函数（要公式，不要概念）

### 3.1 私人价值（IPV）

| 情形 | 均衡出价函数 |
|---|---|
| 次价密封 | $b(v)=v$（弱占优） |
| 首价密封，均匀 $N$ 人，风险中性 | $b^*(v)=\dfrac{N-1}{N}v$ |
| 首价密封，一般对称分布 $F(v)$ | $b^*(v)=v-\dfrac{1}{F(v)^{N-1}}\displaystyle\int_0^{v}F(t)^{N-1}dt$ |
| 风险厌恶（CARA，均匀值） | $b_{RA} > b_{RN}$，一阶近似 $b_{RA}\approx b_{RN}+c\,a\,(v-b_{RN})$ |

【学术共识】[来源: https://en.wikipedia.org/wiki/Auction_theory]

**压价系数 $(N-1)/N$ 速查**（含自己）：

| N | 2 | 3 | 6 | 8 |
|---|---|---|---|---|
| 系数 | 0.50 | 0.667 | 0.833 | 0.875 |

均衡期望剩余 $E[\text{surplus}\mid v]=v^N/N$，随 N 迅速衰减 ⇒ **"人多压价不足"的量化解释**。

### 3.2 共同价值（CV）
核心修正：应出**条件在获胜上的期望价值**，并对信号**再折一层**（对抗赢家诅咒）。 【某篇观点（教学）】

可编码近似（**推断，需实机校准**）：$b \approx \dfrac{N-1}{N}\cdot \mathbb{E}[V\mid s]$

### 3.3 速查对比

| 维度 | 私人价值 | 共同价值 |
|---|---|---|
| 估值来源 | 各人独立 | 共享真值 + 私有噪声信号 |
| 典型现象 | 压价 shading | 赢家诅咒 |
| 次价出价 | 如实 $b=v$ | 需打折，**不再**如实 |
| RET | 成立 | 失效 |

## 4. 性格建模（本文件的核心交付）

### 4.1 理论骨架
- **贝叶斯博弈**：每人有**类型 type**（私有信息）+ 对他人类型的**信念 belief**，按贝叶斯法则更新。 【学术共识】[来源: https://en.wikipedia.org/wiki/Bayesian_game]
- **贝叶斯纳什均衡（BNE）**：给定类型与信念，策略最大化期望效用；每人都至少存在一个（可能混合策略的）均衡。 【学术共识】
- **混合策略纳什均衡**：混合扩展上的纳什均衡；混合策略使对手在若干纯策略间**无差异**。 【学术共识】[来源: https://studyres.com/doc/6364471/mixed-strategy-nash-equilibrium-and-correlated-equilibrium]

### 4.2 【设计建议】性格 → 决策偏好权重表（可直接编码）

**统一决策形式**：NPC 在候选出价 $b$ 上最大化

$$U_i(b)=\alpha_i\cdot\text{Surplus}(b)+\beta_i\cdot P(\text{win}\mid b)-\rho_i\cdot\text{Risk}(b)+\kappa_i\cdot\text{Herding}(b)+\phi_i\cdot\text{Variance}(b)$$

其中 $\text{Surplus}=v-b$，$P(\text{win})$ 由**对他人出价分布的信念**算出。

| 性格 \ 权重 | α 收益 | β 胜率 | ρ 风险厌恶 | γ 加价激进 | κ 从众 | φ 方差/赌博 | σ 诈唬(跳价/托) |
|---|---|---|---|---|---|---|---|
| **激进** | 0.7 | 1.3 | 0.2 | +15%~30% 跳幅 | 0.2 | 0.3 | 0.4 |
| **稳健** | 1.2 | 0.7 | 0.8 | 标准 $(N-1)/N$ | 0.3 | 0.05 | 0.05 |
| **阴险** | 0.9 | 0.9 | 0.5 | 平时压价、末段狙击 | 0.1 | 0.2 | **0.9** |
| **从众** | 0.8 | 1.0 | 0.5 | 贴当前最高价 +1 档 | **0.8** | 0.1 | 0.2 |
| **赌徒** | 0.6 | 1.1 | **−0.3（风险偏好）** | 高方差随机跳价 | 0.2 | **0.9** | 0.5 |

> ⚠ **这张表的数值全部是【设计建议】，不是文献结论**，必须实机调参。

**四条编码要点**
1. **权重决定均衡，不是硬编码动作**：每回合用当前信念算 $b^*=\arg\max U_i(b)$，性格只改权重，**不写 if-else**。
2. **混合策略来自信念不确定**：两个候选出价期望接近时按 softmax 随机化 —— 对应"混合策略纳什均衡"。
3. **信念更新**：观察对手历史出价后按贝叶斯更新后验（"他连续跳价 → 更可能是激进/赌徒"）。
4. **"阴险"就是 shill 的个体版**：σ=0.9 ⇒ 偏好抬价示强 / 末段狙击，而非真实买入。

### 4.3 【设计建议】可复现随机（同种子逐位相同）

**排除 `Math.random()`**（不可设种、不在语言规范内）。 【某篇观点】[来源: https://www.4rknova.com/blog/2026/03/01/mulberry32-rng]

```js
function mulberry32(seed){
  let t = seed >>> 0;
  return function next(){
    t = (t + 0x6D2B79F5) >>> 0;
    let x = Math.imul(t ^ (t >>> 15), t | 1);
    x ^= x + Math.imul(x ^ (x >>> 7), x | 61);
    return ((x ^ (x >>> 14)) >>> 0) / 4294967296;
  };
}
// 字符串种子（FNV-1a 32bit）
function hashStringToUint32(s){
  let h = 2166136261 >>> 0;
  for (let i=0;i<s.length;i++){ h ^= s.charCodeAt(i); h = Math.imul(h, 16777619); }
  return h >>> 0;
}
```

**"同种子逐位相同"三条铁律**
1. **调用顺序必须稳定** —— 某条路径多消耗一个随机数，其后所有值都偏离。
2. 同种子 + 同调用模式 ⇒ 实例逐位相同。
3. **禁止混用 `Math.random()` 与种子 RNG**；不要每帧重设种子，要保留演进状态。

> ⚠ **已知风险**：Mulberry32 有**短周期**问题（如种子 1 落入长度 37956 的小周期）。
> 【某篇观点】[来源: https://gist.github.com/tommyettinger/46a874533244883189143505d203312c]
> ⇒ 正式局用大整数/字符串种子并做冒烟测试，必要时换 PCG32。 【设计建议】

> ✅ 本项目**已满足**第 2、3 条的前提：引擎是纯逻辑、无 `Math.random`、随机全部来自注入的种子 PRNG（见 `game/engine.bundle.js` 头部的设计约束）。本节只是把口径写死，避免日后有人在拍卖里手滑写一个 `Math.random()`。
