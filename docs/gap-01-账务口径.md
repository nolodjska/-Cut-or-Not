## ② 现实依据（规则 + 来源链接）

### 现实里的四条规矩

1. **公司是独立法人**，有独立法人财产；股东仅以出资额为限承担有限责任
   ⇒ **公司账上的钱不是股东的钱**，股东不能直接支配公司财产。
2. **禁止抽逃出资**：股东把出资或公司资金抽回属违法（新《公司法》有专条）。
   ⇒ 游戏里“按持股直接提现”= 抽逃 ⇒ 这就是为什么不能做成“搬走不还”。
3. **利润分配的法定顺序**：当年税后利润 → **先弥补亏损** → **提法定公积金 10%**
   （累计额达注册资本 50% 可不再提）→ 余额才可分配。
4. **拿钱的合法路径**：利润分配（表决决议）/ 减资（须编制财产清单、通知债权人并公告，
   债权人可要求清偿或担保）/ 清算 / 与公司做**公允**交易（关联交易须披露）。
   其中**股东借款**现实中常见，但不是“分钱”，必须**有息、有期、公允、披露**，
   否则仍可能被认定为抽逃或侵占。
