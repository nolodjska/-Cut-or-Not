# 02 公司类型与互动

> 分支：CORP（公司类型与互动）｜基于 `00-策划案-原始冻结版.md`（冻结，不改）
> 所有数值均为 **提议值（待校准）**；标记为「提议值」的条目需要跨分支联合校准，见 §4 待决问题清单。
> 本文档内所有货币单位为「金」，时间单位为游戏内小时（h）/天（d）。Demo 为 3 天 = 72h。

## 0. 摘要

- **统一口径**：净资产 NAV = 现金 + 库存（现价×流动性系数）+ 土地厂房（重置价×0.8）+ 设备（购置价×0.6）+ 应收账款（×0.9）− 负债（本金+应计息）。**无形资产（品牌值、信誉、隐蔽度、情报）一律折算为 0**，否则六家公司不可比。六种公司初始 NAV 全部 = **10,000**（提议值，精确相等，见 §2.1 折算过程）。
- **经济底座**：NPC 终端需求是唯一的价值注入源，日注入 **40,000 金/天**（萝卜 8,000 + 辣椒 12,000 + 人参 20,000），3 天注入 ≈ 120,000 金（提议值）。没有这一端，全场净资产是零和的，A 胜利（净资产 ≥3 倍）在数学上不可能多人达成。**这是原案最大的结构性漏洞（P0）。**
- **A 胜利门槛可行性**：六家 3 天净资产倍数的均衡区间为 **1.9×–2.5×**（提议值），A 门槛 3.0× 需要跑赢平均 25%–55%。纯种植线在无人竞争时可达 3.4×，8 人局下降至 **2.0×–2.4×**，因此 3.0× 门槛在设计上是「可达但不普遍」，保留 3.0×。
- **金融公司不进 Demo**：3 天内金融公司 NAV 上限约 **1.46×**，是六家中唯一在 Demo 时长内结构性无法达成 A 的公司；Demo 用「NPC 银行」公共设施替代（存款 0.4%/d、贷款 2.5%/d），完整版再做玩家金融公司。理由与数字见 §2.10。
- **皮包公司第 1 天能活**：把「不能直接产生收益」改判为「不能产生**生产性**收益，但可产生**服务与套利**收益」。D1 净现金流 ≈ **+3,200 金**（出口订单 700 + 隐蔽撮合 300 + 4 块挂名耕地萝卜 ≈ 2,200），与种植公司 D1 的 +3.5k 同档。见 §2.5。
- **D 路径补丁**：取消「D 被所有人克制」，改为 D 的**多角化对冲**（每持一类资产，价格冲击 −8%，叠加上限 −32%）；D 判定从「四项总分第一」改为「**最少短板原则**」（四项最低项需 ≥ 全场中位数 1.2 倍），并在数学上与其他三路径互斥，另附 3 条专属补强。见 §2.8。
- **垄断判定分母要改**：原案「≥60% 流通量」未定义分母，可被对倒刷量作弊。提议：垄断度 = 自持库存 ÷（全场该作物库存总和 + 24h NPC 净吸纳量 ×0.5），**同一对玩家双向对倒不计入**，皮包隐藏库存不计入分子与分母（摊牌时同时并入）。这条同时让「B 锁仓」变成克制 C 的精确手段。见 §2.8。
- **制造是辣椒市场的超级买家**：3 条产线的辣酱线每天吃 24 单位辣椒 = 全市场辣椒日需求（120 单位）的 **20%**，若全部产线开满则达 **60%**。制造与种植的耦合度高于原案描述，必须靠合约/暗盘才能稳定供货。
- **Demo 公司范围拍板**：种植 **必须**、贸易 **必须**、情报 **必须**、皮包 **建议升为必须**（否则 Demo 的 B 路径没有载体，与「Demo 含 3 条胜利路径」自相矛盾）、制造 **不做**（1 条配方 + 独立市场 + 品牌 = 1.5 人天，ROI 最低）、金融 **不做**（用 NPC 银行替代）。

## 1. 评审：问题与风险

- **[P0] 原案整个经济是零和的，A 胜利（净资产 ≥3 倍）在数学上不可能普遍达成。** 原案 4.4 的互动图里六家公司互为买卖方，没有终端消费者；玩家 A 赚的钱等于玩家 B 亏的钱。8 人局总初始 NAV 80,000，3 天后若无人注入价值，净资产总和仍是 80,000，「净资产 ≥3 倍」最多 2 人达成（需有人破产）。**建议**：引入 NPC 终端需求（出口订单/居民消费）作为价值注入口，日注入 40,000 金（提议值）＝ 全场初始 NAV 的 50%/天，3 天累计 120,000 金；NPC 不还价、不议价、每天刷新，吸收量固定（萝卜 320 单位、辣椒 120 单位、人参 25 单位）。
- **[P0] 原案克制表把 D 标为「被所有人克制」，等价于官方标注「不要选 D」。** 一个不克制任何人、且被所有人克制的选项，在完全理性博弈里是劣策略，D 的四项总分第一的判定条件与 A（净资产最高）高度重叠——净资产最高的人通常四项总分也最高，D 实际上是 A 的另一种写法。**建议**：见 §2.8 的五条补丁（对冲减伤 8%/资产类、最少短板判定、联合体、优先受让权、提名保底），核心是把 D 从「靶子」改成「组织者 + 抗打型」。
- **[P0] 原案 4.2 写「皮包公司不能直接产生收益，只能作为工具」，与 4.1「玩家可选一种公司类型开局」直接矛盾。** 选皮包开局的玩家第 1 天没有任何收入来源，只能烧现金；而其他五家在 D1 都有正现金流。**建议**：改判为「不能产生生产性收益，但可产生服务与套利收益」，并给皮包三项 D1 可收钱的业务（代持 2%/d、隐蔽撮合 3%、资产抵押套利），D1 净现金流 +3,200 金（提议值）。数字与推导见 §2.5。
- **[P0] 原案 Demo 配置自相矛盾：Demo 保留 B 生存胜利路径，但承载 B 的皮包公司被列为「可选」。** 若不做皮包，B 路径就只是「活得久」，任何不操作的玩家自动达成，B 变成必胜/白送路径。**建议**：Demo 把皮包升为「必须」，同时给 B 加最低参与度门槛：负债率 <30% **且** 净资产 ≥ 初始 1.2 倍 **且** 至少 1 项非现金资产发生过公开流通。三条缺一不给 B。
- **[P1] 原案「A 克制 B（有钱就能扛过危机）」是修辞不是机制。** 「有钱」本身不构成攻击手段，A 玩家对 B 玩家没有任何可执行动作。**建议**：给 A 路径机制化攻击——净资产达初始 2.5 倍时解锁「溢价收购」：可以市价 ×1.3 强制要约收购任一玩家的单项资产，对方可拒绝但须支付资产价值 10% 的违约金。这才是「资产碾压」的可执行版本。
- **[P1] 原案「B 克制 C（你不卖，他耗得起）」同样没有机制。** 在纯现货体系里，不卖的人对垄断者毫无影响。**建议**：把垄断判定分母定义为「全场库存」，那么持货不卖的人会直接**稀释**垄断者的占比——B 只要囤着不卖，C 需要的资金量就会按比例上升。例：全场库存 100 时 C 持 60 即达标；若 B 锁仓 50，C 需持有 75 才能维持 60%。这把「隐忍防守」变成一道精确的算术题。
- **[P1] 原案垄断门槛「控制某作物 ≥60% 流通量」没有定义分母，可被对倒刷量作弊。** 两人互相高价买卖 100 次就能把成交量做大、稀释任意玩家的占比。**建议**：垄断度 = 自持库存 ÷（全场该作物库存总和 + 24h NPC 净吸纳量 ×0.5）；同一对玩家之间的双向对倒一律不计入任何统计；皮包公司挂名库存不计入分子与分母，仅在「摊牌披露」时同时并入二者。
- **[P1] 原案 4.4 互动关系图有三处方向错误。** （a）「贸易公司 → 卖情报 → 情报公司」——贸易不生产情报，正确关系是贸易向情报公司卖**订单流数据**（情报的原料）；（b）「制造公司 → 卖产品 → 贸易公司」——制造是供货方、贸易是渠道，应为制造 ⇄ 贸易双向，且贸易向制造提供赊销/包销；（c）缺「种植 → 制造」之外的第二条主链「金融 → 所有（授信）」，导致金融公司像个外部挂件。**建议**：按 §2.9 重画为供需矩阵（6×6）。
- **[P1] 原案 5.2「价格 = 基础价 × (1 + 需求系数 − 供应系数)」在供应系数 >1 时会产生负价格。** 且没有写玩家变现率，导致无法判断生产规模是否过强。**建议**：改用 `P = P0 × clamp(1 + 0.8×(需求−供给)/需求, 0.25, 3.0)`，并定义变现率 `ρ = clamp(1 / (1 + 0.8×(市场总供给/市场总需求 − 1)), 0.35, 1.0)`。按此公式，1 家生产者时 ρ≈0.86，3 家时 ρ≈0.40——**变现率对局内生产者数量极度敏感，Demo 若只有 3 人，种植公司会过强（3.4×）**。
- **[P1] 原案完全没写六家公司的初始资源，只在 10.2 写了「是否实现」。** 没有初始现金/土地/库存，Demo 无法开第一局；「开局强度大致相等」也无法验证。**建议**：采用 §2.1 的初始资源表，六家初始 NAV 全部精确 = 10,000。
- **[P1] 制造公司的品牌溢价原案只说「一旦建立溢价稳定」，没有公式，也没有回本周期。** 按线性累积计算，品牌到 50 需卖出约 700 单位产品 ≈ 完整赛季 2-3 周，Demo 3 天内 Brand 上限约 20（溢价 2.7%），等于该系统在 Demo 里不存在。**建议**：溢价公式 `溢价% = 30 × (Brand/100)^1.5`，并给 Demo 特批制造公司开局 Brand = 25（老品牌），3 天可推进到 35-40（溢价 4.0%–8.0%），否则删掉品牌系统。
- **[P1] 原案情报定价完全空白，10.2 只写「情报价格」需要在下一步确认；三级情报的具体价格、准确率、假情报识破概率一个都没有。** 没有这些数值，情报公司 D1 的期望收入无法计算，也无法判断它会不会成为「零收入公司」。**建议**：L2 定价 600 金/条、L3 拍卖起拍 1,500 金，准确率 70%/85% 基准、封顶 95%，假情报识破概率公式见 §2.4。
- **[P2] 原案「皮包公司可注册多个，但每个都有维护成本」没有上限，也没有说明多注册的好处。** 若每个空壳只带来成本而无收益，理性玩家只会注册 0 个。**建议**：多注册的唯一真实收益是**风险隔离**——被识破时只有被查的那一个实体被冻结，其他实体不受影响。维护费 120 金/实体/天，Cover +5/实体，上限 5 个实体。
- **[P2] 原案拍卖「允许串通」但没有违约成本，联合围标必然变成人人互骗。** **建议**：串通本身不违规，但**违反私下约定的行为会产生「江湖信用」记录**，影响所有后续暗盘撮合的成功率（信用 <50 时暗盘对手方有 40% 概率拒接）。这是软约束，成本低、实现简单。
- **[P2] 原案结算提名「最佳情报商」只统计交易次数与准确率，会奖励刷单。** 卖 100 条 L1 免费情报的行为与卖 10 条 L3 的行为在次数上无法区分。**建议**：该提名的判定改为 `L2 次数 + 3×L3 次数`，并按成交额加权，权重 = 该笔成交额 ÷ 全场情报成交额中位数。
- **[P2] 原案「公司类型 → 胜利路径」是硬绑定（种植→A、贸易→C、情报→D、皮包→B、制造→A/D、金融→A/C），但结算只发 1 个首席。** 若四种路径各有一人达成，首席由「达成度」决定，而四个路径的达成度单位完全不同（净资产倍数 vs 存活天数 vs 流通占比 vs 分位数），不可比。**建议**：统一用「达成度 = 该路径达成值 ÷ 该路径门槛」计算，A=倍数/3.0、C=占比/0.6、B=1.0（固定，B 无梯度）、D=最低项/1.2，首席 = 四者中达成度最高者。
- **[P2] 原案 12.2「别让肝帝碾压，要有上限（仓储容量、地块数量）」，但 4.3 制造公司允许无限扩建产线，与上限原则冲突。** **建议**：统一设硬上限：地块 ≤12、产线 ≤3、仓储上限按公司类型 50–300 单位、空壳实体 ≤5、皮包代持资产 ≤ 自身 NAV 的 2 倍。上限本身也是拍卖标的（扩建许可）。

## 2. 丰富后的设计

### 2.0 统一口径：净资产折算与对齐方法

**NAV（净资产）公式（提议值，全员统一，程序必须用同一函数）**

```
NAV = 现金
    + Σ(库存数量 × 当日结算基准价 × 流动性系数)
    + Σ(土地/厂房重置价 × 0.8)
    + Σ(设备购置价 × 0.6)
    + 应收账款 × 信用系数(0.9)
    − 负债本金 − 应计利息
```

| 科目 | 折算系数 | 理由 |
|---|---|---|
| 现金 | 1.00 | 无争议 |
| 已开垦耕地 / 厂房 | 重置价 × 0.80 | 20% 为流动性折价；破产拍卖成交价 ×0.60 |
| 荒地 / 未开发地 | 重置价 × 0.40 | 需 4h + 300 金开垦 |
| 作物原料库存 | 现价 × 1.00 | 可即时挂单 |
| 加工品库存 | 现价 × 0.90 | 市场日需求较薄，抛售滑点更大 |
| 设备 / 产线 / 车队 | 购置价 × 0.60，每天再 −3% | 残值率 60%，折旧 3%/d |
| 应收账款（赊销 / 放贷本金） | × 0.90；逾期 24h 后 0.60；48h 后 0.30 | 信用折扣 |
| 存款类负债（金融公司吸收的存款） | × 1.00 + 应计息 | 全额计入，利息 0.8%/d |
| **品牌值 / 信誉值 / 隐蔽度 / 情报 / 渠道值 / 线人网络** | **× 0（不计入 NAV）** | 关键决定：无形资产若计入，六家不可比；它们只能通过未来现金流体现 |
| 皮包挂名资产 | 与其他公司同系数，但**变现折价 25%** | 挂名资产的流动性溢价为负 |

**为什么无形资产一律折 0**：情报公司 3 天能积累 5 条 L2 + 2 条 L3，若按拍卖成交价计入 NAV，其账面会凭空多出 8,000–12,000，与其他公司不可比。等价性必须建立在「只有可交易资产计入 NAV」这一条上。

**开局对齐目标**：六家初始 NAV 全部 = 10,000 ± 0。允许偏差 ±3%，当前设计偏差 0%。

**口径说明（必须与其它分支对齐）**

- 六家初始**负债全为 0**。金融公司的「对外放贷 2,000」记在资产侧（应收账款），债务人是一个 NPC 公司（年化 3%/d，每 24h 付息 60 金），开局即存在。这是金融公司唯一的特色资产，也是唯一的首日坏账风险敞口。
- 皮包的挂名资产在公开排行榜上显示为「未披露」，但 NAV 数值真实存在。它与其他五家的差别**不是数值，是可攻击性**：挂名资产不能被直接查封、不能被强制要约收购（除非 Cover <40），代价是变现折价 25%、不能直接参与拍卖公开竞价（须委托他人，付 2% 席位费）。
- 情报公司 6,500 现金看起来最多，但它没有生产能力，D1 全部收入必须来自卖情报，且没有库存缓冲。这是它的结构性风险。

| 人参 | 24h | 3 单位 | 800 | 2,400 | 40% | 1,440 | 25 | 20,000 |

- 高端作物每地块·天收益更高，代价是周期长（资金占用 + 反应慢）、成本率高、垄断门槛更低（50% vs 60%）→ 战场更激烈。
- 固定维护费：**50 金/地块·天**；仓储超限部分每天损耗 8%。
- 变现率 `ρ = clamp(1 / (1 + 0.8×(市场总供给/市场总需求 − 1)), 0.35, 1.0)`（提议值）。ρ 是判断「种地是否过强」的唯一开关，必须由市场分支定稿。

| 项目 | 内容 |
|---|---|
| 天然倾向 | D 综合胜利 |
| 独有资源条（双条） | **信誉值 Rep** 0–100，初始 50；**线人网络 Network** 0–100，初始 20 |
| Rep 恢复 | 卖出情报且买家验证为真 +3（每买家，日上限 +9）；造假未被识破 +2；每 24h 向 50 回归（<50 时 +5，>50 时 −2） |

| Rep 效果 | R <30：买家有 60% 概率拒买（标签「信誉存疑」）；R ≥70：解锁订阅制（400 金/订阅者/24h，Demo 上限 3 人） |

**三级情报定价与准确率**

| 等级 | 名称 | 内容 | 定价 | 基准准确率 | 准确率上限 | 有效窗口 | 交付方式 |
|---|---|---|---|---|---|---|---|
| L1 | 公开消息 | 已发生事件的复述与解读 | 0 金（引流） | 100%（已发生） | 100% | 已过期 | 免费广播 |
| L2 | 内幕消息 | 未来 12h 某作物的方向 + 幅度区间 | 600 金/条 | 70% | 95% | 12h | 定向私聊 |
| L3 | 绝密消息 | 精确事件（时间/作物/幅度）+ 对手持仓摘要 | 拍卖，起拍 1,500 金 | 85% | 95% | 一次性 | 拍卖会 |
| L3 预期成交价 | — | 8 人局、3 天 Demo | 2,500–4,000 金 | — | — | — | 全场唯一，只卖一次 |

**真实情报的实际准确率**

```
准确率 = clamp( 基准准确率 × (1 + Network/200) , 0.50 , 0.95 )
```

- Network 0：L2 = 70%，L3 = 85%
- Network 50：L2 = 87.5%，L3 = 95%（封顶）
- Network 100：L2 = 95%，L3 = 95%
- **L3 拍卖时不公开准确率**，只显示 Network 档位（低 <40 / 中 40–70 / 高 >70 → 对应准确率区间），这是信息博弈的核心机制：买家买的是「概率分布」而不是「事实」。

**假情报识破概率公式**

> 第一版草稿（P = 0.05 + 0.45×(1−Cover) + 0.25×A − 0.15×S）已作废：实测识破概率普遍落在 0.37–0.47，无法区分「骗小白」与「骗同行」，情报公司的核心玩法宽度为零。以下为修正版。

```
P_识破 = clamp( 0.02
              + 0.30 × (T_检查/T_窗口)
              + 0.25 × A_调查
              − 0.35 × (Network/100)
              − 0.20 × (ShellCover/100)
              − 0.10 × S_规模 , 0.02 , 0.90 )
```

其中：
- `T_检查` = 买家投入的核查时间（小时），`T_窗口` = 情报有效窗口（L2 = 12h）；查得越晚越接近到期，越容易识破
- `A_调查` = 买家核验能力：普通公司 0.2；情报公司 0.7；金融公司 0.5；NPC 0.3；有「内幕消息」天赋 +0.3（上限 1.0）
- `ShellCover` = 卖家若有皮包壳（§2.5 的 Cover）→ 假情报也可以用壳背书，这是皮包与情报的第一条协同
- `S_规模` = 该条假情报影响的名义货值 ÷ 全场平均净资产，clamp 0–1（吹得越大越容易被查）

| 场景 | T/T窗口 | A_调查 | Network | Shell | S_规模 | P_识破 |
|---|---|---|---|---|---|---|
| 种植公司买 L2，临到期才查 | 1.0 | 0.2 | 0.2 | 0 | 0.3 | 0.02+0.30+0.05−0.07−0−0.03 = **0.27** |
| 种植公司买 L2，立刻小规模核验 | 0.25 | 0.2 | 0.2 | 0 | 0.1 | 0.02+0.075+0.05−0.07−0−0.01 = **0.065** |
| 情报公司买 L2，全程查 | 1.0 | 0.7 | 0.6 | 0 | 0.5 | 0.02+0.30+0.175−0.21−0−0.05 = **0.235** |
| 情报公司买 L2，全程查 + 卖家有皮包壳 70 | 1.0 | 0.7 | 0.6 | 0.7 | 0.5 | 0.02+0.30+0.175−0.21−0.14−0.05 = **0.095** |

分布合理：骗小白容易（6.5%）、骗同行难（23.5%）、有皮包壳背书极难（9.5%）。**这是提议值，v1 公式作废，以修正版为准。**

**假情报的经济学（关键设计）**

- 制作成本 300 金 + 8h，冷却 24h，每局上限 3 条。
- 假情报**不直接改变价格**，它改变其他玩家与 NPC 的行为；NPC 会按情报行动，因此 NPC 的买卖真的推动价格。这样「舆论操纵」有了物理基础，且不破坏经济守恒。
- 识破后：卖家 Rep −15，买家可发起「公开揭露」→ 全场公告 + 索回 50% 款项（从卖家现金扣，不足则记为债务）。
- 未被识破：+2 Rep（**是的，造假成功反而加信誉**）。这让造假成为一条真实的策略分支，而不是单纯的作恶。

**独有行动**

| 名称 | 消耗 | 耗时 | 产出 | 冷却 | 可被谁用什么反制 |
|---|---|---|---|---|---|
| 采集情报 | 免费额度 1 次 | 即时 | L2 ×1（Network ≥60 时 30% 概率出 L3） | 6h | 无 |
| 铺设线人 | 800 金 | 即时 | Network +8 | 无 | 维护费 15/点/天；被金融公司尽调发现关联 |
| 售卖情报 | 情报 | 即时 | 现金（标价 × f(R)） | 无 | 买家泄露转售（情报价值 −50%）；假情报被识破 |
| 伪造情报 | 300 金 | 8h | 假情报 ×1 | 24h（每局 ≤3 条） | 见识破公式；识破后 Rep −15 + 赔款 50% |

- **侦查加成**：其他公司的所有地下行动（皮包隐蔽操作、裸卖空、洗钱）对情报公司的识破检定 +0.15。
- **零生产能力**：D1 必须靠卖情报活，没有任何库存缓冲。初始 6,500 现金必须在 3 天内变成 3–4 条 L2 销售额 + 1 条 L3 拍卖。

**协同与克制**

| 关系 | 对象 | 机制 | 量化 |
|---|---|---|---|
| 协同 | 贸易 | 卖订单流数据 + 联合做局 | 数据 150 金/份；联合做局（情报 + 砸盘）单次可赚 3,000–5,000 |
| 协同 | 金融 | 卖征信数据（看穿皮包） | 每次调查 300 金手续费，成功率 +0.15 |

### 2.5 皮包公司

**先解决原案的自相矛盾。** 原案 4.3 说皮包「不能直接产生收益，只能作为工具」，4.1 又说玩家可以选它开局——那选皮包的玩家第 1 天靠什么活？

**改判（这是设计决定，不是平衡调整）**：皮包**不能产生生产性收益，但可以产生服务与套利收益**。所有皮包收益来源必须是下列三类之一，不允许凭空生成：
1. **他人支付的服务费**（代持 2%/d、隐蔽撮合 3%、洗钱通道 5%）；
2. **逃避的成本**（手续费减半、灰色收益不被罚没、资产不可被查封）；
3. **隐蔽性带来的价差**（挂名库存不计入公开流通量统计，摊牌才能被发现）。

**皮包公司第 1 天收入结构（提议值）**

| 收入项 | 金额 | 说明 |
|---|---|---|
| 隐蔽出口订单（开局自带 1 张，D1 06:00 交付） | +700 金 | 20 单位萝卜，成本已付（现值 500），溢价 40%；这是「有前情提要的生意」 |
| 隐蔽撮合佣金（若场上有 2 笔 ≥1,000 金暗盘） | +300 金 | 3% × 10,000 |
| 挂名 4 块耕地种萝卜（4×1,500 毛 × ρ 0.7 = 4,200） | +2,200 净 | 成本 30%×6,000 = 1,800，固定维护 200 |
| **D1 净现金流合计** | **≈ +3,200 金** | 对照组：种植 D1 ≈ +3,500 金 |
| 额外杠杆（在金融公司做尽调前） | +2,000–3,000 金现金 | 挂名资产可**重复抵押**（金融公司看不到同一资产已在他处抵押，除非尽调成功）→ 这是皮包 D1 即可用的第一条杠杆 |

**结论**：皮包公司第 1 天净现金流 3,200 金，略低于种植（3,500），差额由「资产不可被查封 + 手续费减半 + 隐藏库存 + 重复抵押杠杆」补偿。**不是靠系统发钱，是靠别人付钱。**

**隐蔽度 Cover 的量化**

| 项目 | 内容 |
|---|---|
| 定义 | Cover 0–100，初始 70，上限 100 |
| 上升 | 每注册 1 个空壳实体 +5（维护费 120 金/实体/天，上限 5 个）；「清理痕迹」+10（500 金，冷却 24h） |
| 下降 | 每完成 1 笔代持 −3；每笔洗钱 −5；每次伪装收购 −8 |
| 自然恢复 | 每 24h +6（若 <70）；>70 时每 24h −3（向 70 回归） |
| 效果（≥60） | 资产不出现在公开排行榜（显示「未披露」） |
| 效果（<40） | 出现在公开排行榜并标注「可疑」，可被强制要约收购 |
| 效果（进入公式） | 直接进入识破概率公式与情报公司调查检定 |

**识破概率公式（每次调查行动触发一次；无调查时每 24h 走基础值）**

```
P_识破 = clamp( 0.05
              + 0.45 × (1 − Cover/100)
              + 0.25 × A_调查
              − 0.15 × S_规模 , 0.02 , 0.90 )
```

- `A_调查`：普通公司 0.2；情报公司 0.7；金融公司尽调 0.5；NPC 0.3（无人调查时 A = 0，只剩基础值）
- `S_规模` = 挂名资产 ÷ 该局玩家平均净资产，clamp 0–1（树大招风）
- 调查行动成本：600 金 + 冷却 12h（每方每天最多 2 次）

| 场景 | Cover | A_调查 | S_规模 | P_识破/天 | 3 天累计被识破 |
|---|---|---|---|---|---|
| 无人调查，自然泄漏 | 70 | 0.0 | 1.0 | 0.05+0.135+0−0.150 = **0.035** | 10.1% |
| 情报公司调查 | 70 | 0.7 | 1.0 | 0.05+0.135+0.175−0.150 = **0.210** | 50.7% |
| 情报公司调查，Cover 养到 90 | 90 | 0.7 | 1.0 | 0.05+0.045+0.175−0.150 = **0.120** | 32.0% |
| 普通公司调查，资产规模 0.5 | 70 | 0.2 | 0.5 | 0.05+0.135+0.050−0.075 = **0.160** | 40.4% |
| 情报公司 + 情报公司反侦察被绕开 | 70 | 0.7 | 1.0 | 0.210，但**每次调查需花 600 金** | 调查方 3 天要花 3,600 金才有 50% 命中 |

**可接受的量级**：被专业调查时 3 天累计 32%–51% 被识破，但调查方要花 3,600 金 + 2 次/天机会成本。**关键预警机制**：非情报公司的调查会向被查者发出「你正在被调查」的提示（情报公司的调查无预警）→ 皮包有 12–24h 反应窗口（提现、转移资产、注销实体）。

**识破后果——资产冻结**

| 项目 | 规则 |
|---|---|
| 冻结范围 | **仅被查实的那个实体**名下的资产（不是全部）——这就是多注册实体的唯一真实收益 |
| 冻结时长 | Demo 12h / 完整版 24h（提议值） |
| 冻结期间 | 不能交易、不能转移、不能提现；**仍可被拍卖** |
| Cover 惩罚 | 强制降到 40，72h 内不能回到 60 以上；公开排行榜可见并标注「已曝光」 |
| 强制清算 | 若被冻结资产 > 该玩家净资产的 50% → 冻结期满后按市价 ×0.7 强制变现，偿还债务后罚没 30% |
| 追索 | 被识破前 24h 内的资产转移会被追索 1 次（转移目标资产原路返回） |

**独有行动**

| 名称 | 消耗 | 耗时 | 产出 | 冷却 | 可被谁用什么反制 |
|---|---|---|---|---|---|
| 注册空壳实体 | 1,200 金 | 2h | +1 实体（Cover +5，维护 120 金/天） | 无 | 金融公司尽调可发现关联（A=0.5，P 见公式） |
| 代持资产 | 承接托管 | 即时 | 服务费 = 托管资产值 ×2%/天 | 无 | 委托方可随时赎回（须提前 12h 通知） |
| 洗钱 | 资金 ×5%（对外）/ 0（对内） | 6h | 灰色资金转干净，不被罚没 | 12h | 金融公司 AML 抽查（P = 0.20/次，罚没 40%） |
| 伪装收购 | 目标股权对价 | 12h | 买走对手 ≤15% 股权，不进公开公告 | 24h | 情报公司调查（P = 0.25/次）；目标方可回购 |
| 资产转移 | 200 金 | 1h | 转移 ≤60% 资产出该实体的名下 | 12h | 转移后 24h 内不可再转移；被识破时可追索 1 次 |
| 清理痕迹 | 500 金 | 2h | Cover +10 | 24h | 无 |
| 重复抵押 | 挂名资产 | 即时 | 借款 = 抵押品 × 抵押率 | 无 | 金融公司尽调识破后额度归零并追缴 |
| 影子撮合 | 无 | 即时 | 撮合他人暗盘，收 3%；不产生公开成交记录 | 无 | 成交双方任一方可赖账（无强制执行）；赖账影响江湖信用 |
| 摊牌披露 | 无 | 即时 | 挂名库存计入公开统计，1h 内结算垄断判定 | 每局 1 次 | 披露即曝光，Cover 归 0 |

**被动特性**

- **债务隔离**：皮包实体的债务不穿透到玩家个人。破产判定只针对该实体 → B 生存胜利的天然载体。
- **手续费减半**：所有通过皮包实体完成的交易，市场手续费 3% → 1.5%。
- **不进公开统计**：挂名库存不计入公开流通量分子与分母。这是皮包在 C 路径上的真正杀手锏——可以悄悄囤到 60% 然后一次性摊牌，触发垄断结算。
- **变现折价 25%**：挂名资产卖出时价格 ×0.75。
- **拍卖受限**：不能直接参与拍卖会公开竞价，只能委托他人（付 2% 席位费）。
- **隐形操盘手提名保底**：结算时若从未被识破且影响过市场价格 → 必得该提名。

**协同与克制**

| 关系 | 对象 | 机制 | 量化 |
|---|---|---|---|
| 协同 | 所有公司 | 代持、洗钱、隐蔽撮合 | 代持 2%/d、洗钱 5%、撮合 3% |
| 协同 | 金融 | 重复抵押获取额外杠杆 | D1 即可多拿 2,000–3,000 金现金 |
| 协同 | 情报 | 反侦察与情报公司互保 | 500 金使对手 12h 内调查全失效 |
| 克制 | 所有人 | 隐蔽囤货 → 摊牌垄断（C 路径暗线） | 挂名库存不透明，对手无法提前发现 |
| 克制 | 金融 | 债务隔离使追偿失效 | 坏账无法穿透，金融公司只能核销 |
| 被克制 | 情报 | 调查行动 | Cover 70 时 21%/天，3 天累计 50.7% |
| 被克制 | 金融 | 尽调 + 抽贷 | 识破重复抵押 → 额度归零 + 追缴 |
| 被克制 | 贸易 | 变现折价 25% | 皮包抛售 10,000 金库存实际只拿回 7,500 |

**Demo**：**建议升为必须**。理由：原案 Demo 含 B 生存胜利路径，但承载 B 的公司被列为「可选」——若不做皮包，B 就退化为「不操作即达成」的白送路径。开发量：Cover 数值 + 一次识破检定 + 冻结状态，约 0.5 人天（比情报公司便宜）。

### 2.6 制造公司

| 项目 | 内容 |
|---|---|
| 天然倾向 | A / D 混合 |
| 独有资源条 | **品牌值 Brand** 0–100（初始 25，Demo 特批；完整版初始 0）+ **产能占用**（同时加工批数 = 产线数，硬约束，无恢复速率） |
| Brand 恢复 | 每卖出一件产品 +0.05 × (售价/基准价)；每完成 1 张出口订单 +3 |
| Brand 衰减 | 每 24h −3（不卖货就掉） |
| 硬上限 | 产线 ≤3 条（3 条以上需拍卖获取「扩建许可」） |
| 设计意图 | 用 Brand 把「持续经营」变成可积累的无形资本，但曲线前期极难、后期陡峭，因此 Demo 必须给初始值否则系统不存在 |

**加工配方表（提议值）**

| 配方 | 输入 | 消耗成本 | 转化率 | 耗时 | 产出 | 产出单位价 | 产出价值 | 增值率 | 能耗/人工 | 批/天 | 净增值/产线·天（ρ_p=0.85） |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 萝卜干 | 萝卜 10 | 250 | 0.60 | 4h | 萝卜干 6 | 90 | 540 | **+116%** | 25 | 6 | **+1,104** |
| 辣酱 | 辣椒 8 | 800 | 0.625 | 6h | 辣酱 5 | 350 | 1,750 | **+119%** | 80 | 4 | **+2,430** |
| 人参精 | 人参 2 | 1,600 | 0.50 | 12h | 人参精 1 | 3,500 | 3,500 | **+119%** | 160 | 2 | **+2,430** |

- 增值率按「产出价值 ÷ 投入成本 − 1」计算，三档都稳定在 +116%–119%，差异只在周期长度、资本占用与原料获取难度。这是刻意的：不给「高级配方必然更高收益」的幻觉，高端的优势是**每单位原料的增值绝对值更大**，劣势是**占用产线更久、原料更难买**。
- 加工品变现率 `ρ_p = 0.85`（提议值），高于作物（0.70），因为加工品市场更薄但竞争者只有制造公司一家类型。
- 新增成本项：**能耗/人工 = 投入价值 ×10%**，加工时立即支付现金。这条让「原料暴跌 → 加工品滞后跟跌」的套利窗口有成本约束。

**加工品独立市场的价格联动**

```
P_加工品(t) = P0_加工品 × (1 + β × Δ_原料(相对基准)(t − 2h)) × (1 + 0.3 × 需求扰动)
β = 0.9   当 |Δ_原料| ≤ 30%
β = 0.5   当 Δ_原料 < −30%（崩盘时消费端托底）
```

| 情形 | 原料变动 | β | 加工品价格变动 | 说明 |
|---|---|---|---|---|
| 辣椒 +20% | +20% | 0.9 | +18%，延迟 2h | 完整传导，但滞后半个加工周期 |
| 辣椒 −20% | −20% | 0.9 | −18%，延迟 2h | 完整传导 |
| 辣椒 −50%（瘟疫砸盘） | −50% | 0.5 | −25%，延迟 2h | **消费端托底**，制造公司抗崩盘 |
| 辣椒 +60%（逼仓） | +60% | 0.9 | +54% | 上游成本几乎全额转嫁 |

**关键机制：2 小时的滞后是全场套利的核心**。情报公司提前 12h 知道「辣椒瘟疫」→ 制造公司提前囤加工品 → 瘟疫发生后原料 −50%，加工品仅 −25% 且晚 2h 才反应。这个窗口不可为 0（否则套利不存在），也不可太大（否则制造躺赢）。

**品牌溢价模型**

```
溢价% = 30 × (Brand/100)^1.5
```

| Brand | 0 | 25 | 40 | 50 | 75 | 100 |
|---|---|---|---|---|---|---|
| 溢价% | 0.0% | **3.75%** | **7.59%** | 10.6% | 19.5% | **30.0%** |
| 达到所需累计销量（完整版） | — | 500 单位 | 800 单位 | 1,400 单位 | 3,750 单位 | 7,000 单位 |
| 达到所需时间 | — | 3–5 天 | 5–8 天 | 1.5–2 周 | 3–4 周 | 赛季末 |

- 曲线设计：Brand 0→50 的边际收益只有 10.6%，50→100 的边际收益有 19.4%。前期铺垫痛苦、后期爆发，符合原案「品牌需要时间积累，但一旦建立，溢价稳定」。
- **Demo 校准结论**：3 天纯销售可累积约 15 点 Brand，达到 40 需要初始 25 点。**因此 Demo 必须给制造公司开局 Brand = 25**（叙事：一个有老招牌的作坊），3 天可推到 35–40（溢价 4.0%–7.6%）。若不给初始值，品牌系统在 Demo 里等于不存在，应直接砍掉。

**独有行动**

| 名称 | 消耗 | 耗时 | 产出 | 冷却 | 可被谁用什么反制 |
|---|---|---|---|---|---|
| 加工 | 原料 + 能耗 10% | 配方耗时（4/6/12h） | 加工品入库 | 产线占用 | 种植/贸易断供原料；极端情况下原料价涨幅吞掉全部增值 |
| 品牌投资 | 1,000 金 | 12h | Brand +8 | 无 | 无 |
| 出口接单 | 产线占用 | 6–12h | 现金 = 加工品价 ×1.2 | 24h | NPC 拒收（超时/质量不达标，损失该批） |
| 产线扩建 | 4,000 金 | 12h | +1 产线 | 无 | 破产时被拍卖夺走 |
| 纵向整合 | 地块/仓库对价 | 按收购 | 自供原料 | 无 | 被上游反收购 |
| 降价清仓 | 库存 | 即时 | 快速变现 ×0.85 | 6h | Brand −5 |

**被动特性**

- **纵向整合奖**：自持 ≥2 条产线且自供原料 ≥30% 时，增值率额外 +10%（绝对加成，不乘算）。
- **消费端托底**：原料跌幅 >30% 时加工品传导系数降为 0.5（见上表），是对抗 C 垄断者的天然对冲工具。
- **大客户依赖**：出口订单是超额收益源（×1.2），但需要 6–12h 交付周期，且 NPC 会因价格或信誉拒收。
- **辣椒吞噬者**：3 条辣酱产线每天吃 24 单位辣椒 = 全市场辣椒日需求（120 单位）的 20%；若三条产线全开且都做辣酱，日耗 96 单位 = **60% 的全市场辣椒需求**。制造公司是 C 路径（垄断辣椒）的最佳盟友，也是最大受害者。

**协同与克制**

| 关系 | 对象 | 机制 | 量化 |
|---|---|---|---|
| 协同 | 种植 | 长期供料合约（暗盘或定向挂单） | 稳定供料可让产线利用率从 60% 提到 95%，日增值 +1,200 |
| 协同 | 贸易 | 包销 + 赊销 | 包销 3 条产线产出，日周转 4,500 金货值 |
| 协同 | 情报 | 提前知道原料事件 → 囤加工品 | 一次成功的瘟疫套利可赚 3,000–5,000 |
| 协同 | 金融 | 产线/库存抵押扩产 | 设备抵押率 40%（六类最低），库存 60% |
| 克制 | 贸易 | 拒绝其压价（自建销售） | 制造自营出口可绕过贸易的 10%–15% 压价 |
| 克制 | 种植 | 集中采购压低原料价 | 单日 96 单位采购量足以在薄市场压价 8%–12% |
| 被克制 | 种植 | 断供原料 | 断供 12h 停 2 批辣酱，损失 3,480 金 |
| 被克制 | 贸易 | 压加工品价 | 贸易是加工品唯一分销渠道，可压 10%–15% |
| 被克制 | 情报 | 假事件引导扩产 | 全押一条错误配方线 ≈ 4,000 金扩建费打水漂 |

**Demo**：**不做**（推荐）。理由：制造公司需要三个子系统同时上线才能成立——配方系统、加工品独立市场（含 β 传导与 2h 滞后）、品牌值曲线，合计约 1.5 人天，是六家中最贵的；而它同时又不是任何一条胜利路径的独占载体（A/D 都能由其它公司达成）。原案标「可选」，建议明确降级为「不做」，把预算投给皮包（0.5 人天，解锁 B 路径）。完整版必须做。

### 2.7 金融公司

| 项目 | 内容 |
|---|---|
| 天然倾向 | A / C 混合 |
| 独有资源条 | **流动性储备 Liquidity** 0–100，初始 60 |
| 公式 | `Liquidity = clamp( 现金 ÷ (存款 + 应付 + 其他流动负债) × 100, 0, 100 )` |
| 上限 / 恢复 | 上限 100；每 24h +8（向 60 回归）；卖出资产 +（金额/应付）×20 |
| 下降 | 每放出 1 笔贷款 −（放贷额 ÷ 自有资金）×40；吸收存款 −（存款额 ÷ 应付）×100 |
| 惩罚 | Liquidity <30：禁止新增放贷；所有借款人可要求提前还款（挤兑）；<15：触发信用事件，所有未到期贷款被视为到期 |
| 设计意图 | 把「放贷越多越危险」变成一条可视的压力条，让金融公司全程处在「多贷少贷」的两难里 |

**存贷利率（提议值）**

| 项目 | 利率 | 说明 |
|---|---|---|
| 存款（玩家存入金融公司） | **0.8%/天**（24h 复利） | 完整版；这是其他玩家闲置资金的去处，也是金融公司的负债 |
| 贷款（金融公司放出） | **2.0%–4.0%/天**，按风险定价 | 抵押率越低、周期越长、借款人信誉越差 → 越接近 4.0% |
| NPC 银行基准（公共设施，Demo 用） | 存款 0.4%/d，贷款 2.5%/d | 无风险定价，额度上限按抵押品计算，不做风控 |
| 逾期罚息 | **+1.5%/天**（复利） | 逾期第 2 天起额外本金 5% 违约金 |
| 存贷利差 | 1.2%–3.2%/天 | 金融公司的基础毛利来源 |
| 风险定价公式 | `利率 = 2.0% + 0.6% × (1 − 抵押率) × 3 + 0.4% × (贷款期限/1天) − 0.2% × min(信用等级,3)` | 抵押率 65% 的 1 天期 → 2.0%+0.63%+0.4% = **3.03%/天** |

**授信额度算法**

```
授信额度 = min( Σ(抵押品价值 × 抵押率) × 调整系数 , 放贷人可放贷余额 , 单笔上限 )

调整系数 = 1.00
         − 0.05 × (逾期历史次数)
         + 0.10 × (情报公司，数据透明)
         + 0.10 × (还清过 ≥1 笔贷款)
         + 0.30 × (皮包公司虚增财报，被识破则归零并追缴)
         × 0.85  (皮包公司，账面不可见资产不计入授信)

放贷人可放贷余额 = 自有资金 × 3（Demo） / × 5（完整版，牌照杠杆）
单笔上限 = 放贷人现金 × 0.6
单客户集中度 ≤ 30%，超限则该笔利率 +0.5%/天
```

### 2.8 克制关系复核与 D 路径补丁

**复核原案克制表**

| 原案条目 | 是否成立 | 问题 |
|---|---|---|
| A 克制 B（有钱就能扛过危机） | **不成立** | 「有钱」不是攻击手段，A 玩家对 B 玩家没有任何可执行动作 |
| B 克制 C（不参与斗争，垄断者打不到你） | **不成立** | 在纯现货体系里，不卖的人对垄断者没有影响 |
| C 克制 A（控制市场，让资产贬值） | **成立** | 有明确机制：垄断定价 → 对手库存与净值同步缩水 |
| D 不克制任何人，被所有人克制 | **不成立** | 等于官方标注「不要选 D」；且 D 的判定条件与 A 高度重叠 |

**补丁 1：机制化「A 克制 B」——溢价收购**

净资产达初始 2.5 倍时解锁「溢价收购」：可以市价 ×1.3 对任一玩家发起强制要约，收购其**单项资产**；对方可拒绝，但须支付资产价值 10% 的违约金（现金，不足则记债务）。冷却 24h。

- 数字：B 玩家（净资产 12,000，主要资产是 8,000 的耕地）若被两次要约，拒绝代价 1,600 金 = B 净资产的 13%。B 的「隐身防守」不再是免费的。

**补丁 2：机制化「B 克制 C」——锁仓稀释**

| 定义 | 规则 |
|---|---|
| 垄断度 | `自持库存 ÷ (全场该作物库存总和 + 24h NPC 净吸纳量 × 0.5)` |
| 对倒剔除 | 同一对玩家之间的双向买卖不计入任何统计（防刷量） |
| 皮包隐藏库存 | 不计入分子也不计入分母；摊牌披露时同时并入（披露后 1h 内结算垄断判定） |
| **锁仓宣告** | 任何玩家可宣告某作物锁仓 X 天（X ≤3），期间**不卖出**该作物 |
| 锁仓效果 | 锁仓者库存**计入分母**，直接稀释所有人的垄断度 |

- 算例：全场萝卜库存 100（其中 B 锁仓 40，C 持有 60），C 垄断度 = 60/100 = 60%，**刚好达标**。若 B 把库存加到 50，C 需要持有 75 才能维持 60%——相同的达标比例需要多 25% 的资金。**这就是「你不卖，他就得花更多的钱」的精确版本。**
- 这同时解释了原案为什么用「流通量」而不是「产量」做垄断门槛：门槛是持仓占比，那么**持货不卖的人就是垄断者最直接的敌人**。

**补丁 3：取消「D 被所有人克制」——多角化对冲**

| 资产类别（4 类） | 现货 / 加工品 / 股权 / 债权（或情报合约） |
|---|---|
| 减伤 | 每持有 1 类资产，受到的价格冲击 **−8%**，最多叠加至 **−32%** |
| 算例 | C 垄断辣椒使辣椒价格 −40%。纯种植公司净资产 −40%；D 持 4 类资产，辣椒现货只占其资产 30% → 实际净资产变动 = −40% × 0.30 × 0.68 = **−8.2%** |
| 结论 | D 不是「被打死」，是「打不疼」。这是「全能」的真实含义，也是它与 A（单点极致）的数学区分 |

**补丁 4：D 的判定改为「最少短板原则」**

原案「种地/交易/收购/拍卖四项总分第一」与 A（净资产最高）高度重叠，必须改：

```
D 达成度 = min(种地分, 交易分, 收购分, 拍卖分) ÷ 全场该项中位数
达成条件：四项均 ≥ 全场中位数 × 1.2
```

- 这会与其它三种胜利在数学上互斥：一个人不可能同时是最大垄断者（单点极致）且四维均衡。8 人局中，四项都在中位数 1.2 倍以上，意味着「每项都在前 3 名边缘」，需要真正的多线经营。
- 对照原案：原案的总分第一只需某一项极高即可（例如只种地），新版必须没有短板。

**补丁 5：D 专属补强（两条，防止 D 成为「均衡但平庸」）**

| 补强 | 内容 | 冷却 | 设计意图 |
|---|---|---|---|
| 联合体 Consortium | 邀请其他玩家组成临时联盟（≤4 人）：联盟内交易免手续费 + 共享 20% 情报（所有成员的 L2 自动互相可见） | 48h，最长维持 24h | D 从「靶子」变「组织者」，呼应原案「经济命运共同体」提名 |
| 优先受让权 | 「跨类交易」每完成 1 笔（把 A 类资产卖给 B 类公司）累积 10 整合点；满 100 点获得：在任何破产清算中可用市价 **90%** 优先受让 1 项资产 | 每局 1 次 | 给 D 一条中后期追分路径（4–6 周赛季关键） |

**补丁 6（体验层）：B 路径的最低参与度门槛**

原案 B 只需「存活 + 负债率 <30%」，在 3 天 Demo 里任何不操作的玩家自动达成 → 必胜路径。加三条，缺一不给 B：

1. 负债率 <30%；
2. 净资产 ≥ 初始 1.2 倍（8 人局 3 天均衡倍数 1.9–2.5×，1.2× 是「至少参与了」的门槛）；
3. 至少 1 项非现金资产发生过公开流通（买入或卖出的成交量 ≥ 500 金）。

**价格规则的硬约束（三条，防止套利漏洞）**

1. **参考价可见**：暗盘双方在出价界面都能看到当前市价 ±5% 的公允参考。偏离参考价 50% 以上的交易被系统标记为「异常」。
2. **异常交易可被调查**：被标记的交易成为金融公司（反洗钱，P=0.2）与情报公司（关联交易，P=0.25）的调查线索。这是暗盘唯一的约束——否则暗盘会变成无限自由的白嫖通道，所有公开市场崩解。
3. **滑点必须存在**：任何单笔成交量 ≥ 该作物日需求 10% 的成交，必须产生 3%–8% 的价格滑点。**没有滑点，砸盘与逼仓都不成立，C 路径失去全部战术深度。**

## 4. 待决问题清单

**Q-CORP-01｜A 胜利门槛 3.0× 是否保留**
- 为什么必须人定：门槛直接决定「3 天 Demo 里有几个人能赢」。我的核算显示均衡倍数 1.9–2.1×，3.0× 需要跑赢平均 43%–58%。
- 推荐默认：**保留 3.0×**，并确认 NPC 日注入 40,000 金。
- 备选：降到 2.5×（跑赢 25%–32%）；或提高 NPC 注入到 60,000 金/天。
- 后果：保留 3.0× 且注入不足 → 全场只有 1 人达成 A，甚至 0 人（首席只剩 C）；降到 2.5× → A 达成者 2–3 人，可能超过「胜利路径达成者 2-4 人」的上限。

**Q-CORP-02｜NPC 需求注入量**
- 为什么必须人定：这是全场净值增长的唯一来源，决定整个经济是正和还是零和。任何公司数值都建立在它之上。
- 推荐默认：**40,000 金/天**（萝卜 8,000 / 辣椒 12,000 / 人参 20,000，3 天共 120,000，约为 8 人局初始总 NAV 的 1.5 倍）。
- 备选：30,000 / 天（更紧绷，偏零和博弈）；60,000 / 天（通胀快，A 容易达成）。
- 后果：注入过低 → 净值普遍不涨，A 胜利只能靠抢，B 生存变成最优策略，全场变成纯 PvP；注入过高 → 人人达标 A，A 称号贬值。

**Q-CORP-03｜公司数量与局内人数**
- 为什么必须人定：变现率 ρ 对局内生产者数量极度敏感（1 家 0.86 → 3 家 0.40），直接决定种植是否过强。
- 推荐默认：**Demo 4 人起（2 种植 + 1 贸易 + 1 情报）+ 1 NPC**；完整版 8 人 + 3–5 NPC。
- 备选：Demo 3 人（成本最低，但种植会过强到 3.4×，需额外补丁）。
- 后果：3 人局必须给市场加「NPC 竞争供给」（NPC 也种地）来压 ρ，否则种植一枝独秀。

**Q-CORP-04｜垄断判定分母的口径**
- 为什么必须人定：原案「≥60% 流通量」没定义分母，可被对倒刷量作弊，直接决定 C 路径是否成立。
- 推荐默认：`自持库存 ÷ (全场该作物库存总和 + 24h NPC 净吸纳 ×0.5)`，剔除同对玩家对倒，皮包隐藏库存两端不计。
- 备选：分母只算 24h 成交量（原案字面意思，但可刷量）；或只算全场库存（对囤货者最有利）。
- 后果：选成交量口径 → C 路径被刷量游戏化；选全场库存 → B 的锁仓成为克制 C 的精确手段（推荐理由）。

**Q-CORP-05｜皮包公司 D1 生存机制是否采用「三收入」方案**
- 为什么必须人定：这直接推翻原案「皮包不能产生收益」的定性描述，属于设计层决策，不是数值调整。
- 推荐默认：**采用**（隐蔽出口订单 700 + 撮合 300 + 挂名耕地 2,200 = +3,200 金），改判为「不能产生生产性收益，可产生服务与套利收益」。
- 备选：给皮包一次性开局补贴 3,000 金（简单但破坏经济守恒）；或把皮包从可开局公司中移除（则 B 路径失去载体）。
- 后果：采用 → 需要额外实现「隐蔽收入」的记账（不进公开统计）；用补贴 → 玩家会觉得皮包开局不公平。

**Q-CORP-06｜皮包被识破的资产冻结时长**
- 为什么必须人定：冻结 12h（Demo）还是 24h（完整版），以及冻结范围是「单个实体」还是「全部资产」，决定皮包是高风险高收益还是一击必死。
- 推荐默认：**冻结 12h（Demo）/ 24h（完整版），仅限被查实的那个实体**，40% 概率被查实体强制清算、罚没 30%。
- 备选：冻结全部资产 24h（更狠，但会让皮包变成一次性赌博）；或只降 Cover 不冻结（惩罚太轻，皮包无风险）。
- 后果：范围改全部 → 皮包 3 天累计被查概率 50%，等于一半的局直接出局，理性玩家不选；范围改单实体 → 多注册实体（每个 1,200 金 + 120 金/天）成为真实策略。

**Q-CORP-07｜D 路径的两条补强是否全部保留**
- 为什么必须人定：联合体（免手续费 + 共享 20% 情报）与优先受让权（破产资产 90% 价优先受让）都是新增系统，有开发成本与平衡风险。
- 推荐默认：**两条都保留**，联合体设 48h 冷却 + 最长 24h 维持，优先受让权每局 1 次。
- 备选：只保留联合体（砍掉优先受让权，省 0.3 人天）；或两条都砍，只留对冲减伤 + 最少短板判定。
- 后果：只留对冲与短板 → D 变成「抗打但赢不了」的陪跑；两条都上 → D 在 4–6 周赛季的中后期可能过强（联合体共享情报在联盟规模 4 人时收益翻倍），需要按人数缩放共享比例。

**Q-CORP-08｜金融公司在 Demo 的处理方式**
- 为什么必须人定：这是「砍一个公司」级别的范围决策。我的数字显示 3 天 NAV 上限 1.46×，结构性无法达成 A/C。
- 推荐默认：**玩家金融公司不做，NPC 银行必做**（存款 0.4%/d、贷款 2.5%/d、抵押率表同 §2.7、强平规则同 §2.7）。
- 备选：Demo 做简化版金融公司（只放贷、不吸存、无 Liquidity 条，约 0.6 人天）；或完全不做金融（连 NPC 银行也不做）。
- 后果：不做 NPC 银行 → 破产判定（现金流为负无法融资）与裸卖空无法闭环，直接破坏 Demo 验证目标「种地→市场→打压→收购」的第四段。

**Q-CORP-09｜制造公司是否进 Demo**
- 为什么必须人定：原案标「可选」，我建议降级为「不做」，节省 1.5 人天。
- 推荐默认：**不做**，把预算给皮包（0.5 人天，解锁 B 路径）。
- 备选：做「1 条配方 + 无品牌」的精简版（约 0.8 人天，只验证「加工增值」这一件事）。
- 后果：不做 → Demo 只有 4 家公司，「产业链整合」与「纵向整合度」提名无法演示；做精简版 → 品牌系统缺失，原案 4.3 的四条设计有两条没被验证。

**Q-CORP-10｜情报准确率与假情报识破公式的系数**
- 为什么必须人定：这决定「情报公司能不能骗人」与「情报公司会不会被骗」的整个博弈宽度。我已给出 v2 修正版公式，但系数需要实测。
- 推荐默认：**采用 v2 公式**（基础 0.02 + 0.30×时间比 + 0.25×调查能力 − 0.35×Network − 0.20×ShellCover − 0.10×规模），实测区间 6.5%–27%。
- 备选：v1 公式（识破概率普遍落在 37%–47%，无法区分情报公司与小白）；或把 Network 权重从 0.35 降到 0.25（提高骗人难度）。
- 后果：识破概率普遍过高 → 假情报没人用，情报公司的核心玩法消失，只剩卖 L2；普遍过低 → 全场被假情报支配，市场价格信号失效。

**Q-CORP-11｜三级情报的具体定价**
- 为什么必须人定：价格决定情报公司 D1 是否有收入。原案 10.2 自己承认这是待定项。
- 推荐默认：**L1 免费、L2 600 金/条、L3 拍卖起拍 1,500（预期成交 2,500–4,000）**，成交价再乘信誉系数 f(R) = 0.6 + 0.4×(R/100)。
- 备选：L2 定价 400（销量优先）或 900（利润优先）；L3 起拍 2,500。
- 后果：L2 定价 600 且卖家 Rep 50 → 实收 480，情报公司 3 天需卖出 6–8 条才能达到均衡倍数 1.90×；定价 900 → 买家（8 人局只有 7 个潜在买家）购买意愿下降，销量腰斩。

**Q-CORP-12｜品牌溢价的 Demo 初始值**
- 为什么必须人定：Brand 从 0 开始累积，3 天只能到 15 点（溢价 1.7%），等于品牌系统在 Demo 里无效。
- 推荐默认：**Demo 制造公司开局 Brand = 25**（溢价 3.75%），3 天推至 35–40（4.0%–7.6%）。
- 备选：不给初始值，Demo 直接砍掉品牌系统；或给 Brand = 40（溢价 7.6%，开局即显著）。
- 后果：给 25 需要写一句叙事（「一个有老招牌的作坊」）；给 40 → 制造 D3 溢价可达 10%，与其他公司的 1.9–2.1× 均衡倍数偏离，需要重新配平制造的其他收入项。

**Q-CORP-13｜金融公司的单笔放贷上限与杠杆倍数**
- 为什么必须人定：决定金融公司是「稳健中介」还是「全场的庄家」。放贷上限过低则金融无收益，过高则金融能靠杠杆直接垄断。
- 推荐默认：自有资金 ×3（Demo）/ ×5（完整版）；单笔 ≤放贷人现金 ×0.6；单客户集中度 ≤30%，超限利率 +0.5%/d；强平维持担保比例 120%。
- 备选：×2 / 单笔 ≤0.4（更保守，金融更难赢）；单客户不设限（金融可以梭哈一个客户，风险集中）。
- 后果：杠杆 5× 且单客户不设限 → 金融公司可在完整版一局内用 2 个客户锁定某作物 70% 库存，C 路径变成金融专属。

**Q-CORP-14｜强平滑点 −30% 是否过高**
- 为什么必须人定：它同时决定「违约成本」与「市场连锁崩盘」的烈度。滑点越高，金融越赚（拿到的抵押品越便宜）也越容易引发系统性崩盘。
- 推荐默认：**市价 ×0.7**，且抛售量 ≥该作物日需求 30% 时额外触发价格 −15%～−25%。
- 备选：×0.8（温和，借款人损失小）；×0.6（暴力，一次强平可直接击穿市场）。
- 后果：×0.6 + 连锁 −25% → 一次强平可能让 2 家持有该作物的公司同时破产，Demo 4 人局会变成「一家爆仓全场结束」。

**Q-CORP-15｜「江湖信用」系统是否进 Demo**
- 为什么必须人定：它是暗盘与拍卖串通的唯一软约束（赖账成本），但也是纯新增系统。
- 推荐默认：**进 Demo 但极简**（一个 0–100 数值 + 暗盘被拒接概率 `P = clamp((50 − 信用)/100 × 1.5, 0, 0.6)`，无 UI 面板，只在暗盘界面显示）。
- 备选：不进 Demo，暗盘完全裸奔（赖账零成本，暗盘会变成骗局温床）。
- 后果：不进 → Demo 的暗盘体验可能是「被骗一次后再也不暗盘」，而暗盘正是皮包公司唯一的收入来源；进 → 需要 0.2 人天。

**Q-CORP-16｜无形资产不入 NAV 是否会被玩家认为是「贬值」**
- 为什么必须人定：这是全部跨公司比较的基础（我坚持折 0），但玩家会看到自己 Brand 40 / Rep 70 却不加净值。
- 推荐默认：**不入 NAV，但在 UI 上显示「无形资产估值」（= 该资源的理论年化收益，仅展示不计分）**，并在教学里明说「无形资产通过未来的现金流体现」。
- 备选：按理论收益资本化计入 NAV（如 Brand 40 → +2,000），则六家不可比，本分支全部初始对齐失效。
- 后果：不计入 + 无说明 → 情报/皮包/制造玩家感觉「我攒了一堆东西却不值钱」；计入 → 需要给 6 种无形资产各定资本化率，是 6 个新的平衡参数。

**Q-CORP-17｜皮包的「摊牌披露」是否允许**
- 为什么必须人定：这是皮包达成 C 路径的唯一方式（隐藏库存不计入垄断分子，必须主动披露才能结算），但披露即曝光。
- 推荐默认：**允许，每局 1 次**，披露后 1h 内结算垄断判定，同时 Cover 归 0、全部挂名资产曝光。
- 备选：不允许（皮包永远无法达成 C，只能做 B 与辅助）；或允许随时披露（无次数限制，威慑力过强）。
- 后果：允许 → 皮包有了一个戏剧性的收网时刻（符合「结算是一场颁奖礼」）；不允许 → 皮包在四路径中只能走 B，公司深度减半。

**Q-CORP-18｜对倒剔除的判定门槛**
- 为什么必须人定：这是反刷量作弊的唯一防线，但过严会误伤正常的高频交易与做市行为。
- 推荐默认：**同一对玩家在 24h 内双向成交、且两笔成交的净额差 <20% 时判定为对倒**，不计入垄断统计与波动率贡献。
- 备选：按价格偏差判定（两笔成交价偏离市价 <3% 且方向相反）；或不判定（信任玩家，Demo 不做反作弊）。
- 后果：不判定 → C 路径可被「两人对刷 100 次」直接废掉；门槛过严 → 贸易公司的做市双边挂单会被误判为对倒（做市本来就双向成交），误伤 Channel 系统。

**Q-CORP-19｜「溢价收购」是否会被滥用为报复工具**
- 为什么必须人定：这是 A 克制 B 的唯一机制化手段，也是社会关系风险点（原案 12.2「社交要轻，避免关系破裂」）。
- 推荐默认：**净资产 ≥2.5 倍解锁，冷却 24h，每局最多 2 次**；被收购方拒绝的违约金 = 资产价值 10%（现金，不足记债务）。
- 备选：改为「优先购买权」（对方必须给出价最低的竞标者一个匹配机会，无强制力）；或每局 1 次。
- 后果：不限次数 → 全场唯一的 A 路径玩家可以逐个点名，4 人 Demo 变成 1v3 的霸凌局，与「复仇机制」原则冲突。
