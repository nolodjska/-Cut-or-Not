# 试玩记录（往复循环的留档）

> 用户定的循环：**派试玩员 → 收集玩家疑问 → 据此优化 → 再派**。
> 试玩员被**禁止读源码与文档**（读了就会用设计者语言提问，信噪比为 0）。
>
> ⚠️ **方法学限制（必须随每轮一起读）**：试玩子代理**没有浏览器工具**，无法真的点界面。
> 它用的是替代方案「剥掉 `<script>`/`<style>` 后提取可见文字」。
> 但本项目 UI 全是 **JS 运行时渲染**的，所以静态 HTML 里**只有 8 行字**（见第 2 轮）。
> **⇒ 它的清单只覆盖那 8 行，不能当作"整个游戏的玩家体验"。**
> 凡它说"我没看到 X"，**不等于"游戏里没有 X"**，只等于"X 在 JS 里画"。

### 第 2 轮 · 顺带补的一道闸（因为我真把它写错了）

我在改开场文案时写了 `**你持有公司**` —— 那是 **Markdown 加粗**，但目标是 HTML，
**玩家会在屏幕上看到两个星号**。前两道闸（红线词 / 术语）**都查不出来**。

⇒ `tools/lint-copy.cjs` 新增**第三道闸：Markdown 泄漏**。
- 判据故意收窄：**只有中文与 `**` 同处一行**才算（JS 幂运算符 `**` 不会和中文同行）
- 判据抽成 `hasMdLeak()`，**自检与生产路径共用同一份逻辑**（否则自检只证明了一个平行实现）
- 自检含**正例（必须命中）+ 反例（纯 ASCII 不得误报）**

⚠️ **同一个错我犯了两次**：第一次写 `**`，第二次“修复”时又把错字「一**萄**」（应为「一**茬**」）复制了进去。
**两次都不是闸门抓到的，是 diff 让我看见的。**
