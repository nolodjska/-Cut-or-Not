## 1. 一句话

> 一本摊在桌上的牛皮纸账本，**页面上嵌着一台还亮着的行情仪表**。

`docs/10` 原来的比喻是「一块被搬进深夜行情终端的菜地」。v2 保留这个「暖 × 冷」的张力，但把主次调过来：**纸是主体（暖、粗糙、有纤维），屏是嵌进去的窗口（冷、发光、高饱和）**。所以不再是"深色终端里放了点土"，而是"账本里嵌了一台仪表"。

### 3.1 语义色 / 自然色分离（保留，仍是硬规则）
- 语义色只用于**数据、按钮、状态**，永不用于自然物。
- 自然色只用于**插画**，永不用于数据。
- 辣椒仍按 `docs/10` 裁定用晒干红 `#a84a3c` + 土棕暗部，**绝不用 `--down`**。

### 3.2 为什么新增 `--up-ink` 等三个变量（一处有意的妥协）
`--up/--down/--gold` 是给深底设计的高亮色，直接放在浅纸面上对比度不足（`#35d07f` on `#e9dcbd` 约 1.9:1）。
所以：**纸面上的文字**用 `--up-ink/--down-ink/--gold-ink`；**「屏」内**（`.crop`/`.screen`）仍用原版高饱和色。
canvas 走势图（`ui.js:444` 硬编码 `#35d07f`/`#ff5c5c`）**保持不动** —— 它画在深色的「屏」里，原色正合适。

## 4. 质感与纹理（全部内联 SVG，不引外部图片）

三个 SVG `feTurbulence` 噪点，写进 CSS 变量，保证**单文件交付不被破坏**：

| 变量 | 用途 | 参数 |
|---|---|---|
| `--tx-grain` | 纸纹（冷压纸颗粒） | `fractalNoise` `baseFrequency=.9` `numOctaves=4`，opacity .055 |
| `--tx-fiber` | 纸纤维（备用） | `baseFrequency=.02 .55`，opacity .07 |
| `--tx-wood` | 木纹（地块木牌） | `baseFrequency=.012 .35`，opacity .16 |

叠法：`background-color` 打底 + `background-image:var(--tx-*)`。**不用 `#app::before` 覆盖层** —— 覆盖层会引入 `z-index`/`pointer-events` 风险，而叠在 `background-image` 上零风险。

## 6. 动效规范（Q5「复古、拟真」）

### ⚠ 一条决定成败的工程约束
`ui.js` 的 `render()` **每 120ms 重写一次 `#view` / `#toasts` 的 `innerHTML`**。
任何放在这两个容器里的入场动画，都会每帧重新播放 → 看起来像抽搐。
（这条同样是 `tools/tab-click-race.test.cjs` 里那个真实故障的同源约束。）

**所以动效只允许两类：**
1. **交互驱动**（`:hover` / `:active` / `:focus`）—— 不会重播；
2. **挂在"只在变化时才重写"的元素上** —— `#tabs`（已被源码守卫 `if (box.innerHTML === html) return;` 保护）、`#ovStart` / `#ovEnd`（只在开局/结算建一次）。

   > ⚠ `#ovStart` 的"只建一次"是有前提的，**依赖选中态不再重建 DOM**。
   > 2026-10-08 修过一个真实缺陷：公司/节奏按钮原先点一次就 `paint()` 重建整个浮层 innerHTML，
   > 于是 `.modal` 的入场动画每点一次就重播一遍（用户反馈就是"选公司会重载/闪动"）；
   > 同时还会把浮层滚回顶部，并把手输/粘贴的世界种子冲回默认值（渲染的是闭包里的旧 `seed`）。
   > 现已改为 `sync()` 就地切 `.on` class，11 项自检全通过（见 `dist/start-pick-test.html`）。
   > **新增开局浮层交互时，必须沿用"就地更新"，不要重建 innerHTML。**

**`#view` 内的元素一律不加 `animation`。**

已实现：

| 动效 | 触发 | 落点 |
|---|---|---|
| 盖章 `stampIn` | 新提示 | `.toast`：`scale(1.35) rotate(-7deg)` → 回弹到正 |
| 翻页 `pageOpen` | 开局 / 结算 | `#ovStart .modal`、`#ovEnd .modal` |
| 开幕 `curtainDrop` | 结算首席卡 | `#ovEnd .aw.chief` |
| 朱印呼吸 `inkSeal` | 常驻 | `.tab.on::after`，2.6s 交替 |
| 成熟呼吸 `readyPulse` | 地块成熟 | `.plot.ready`（类由状态决定，跨帧稳定） |
| 按下陷落 | 点击 | `.btn:active{transform:translateY(2px)}` |

`prefers-reduced-motion: reduce` 时全部关闭。

1. 把产物放进 `assets/raw/`，命名 `B01-xxx.png`（`B` = 批次 5 构件）。
2. 跑 `python tools/prepare-assets.py` → 生成 `dist/assets/*.webp`。

## 9. 已知妥协 / 技术债

| 项 | 说明 | 建议 |
|---|---|---|
| `!important` 修输入框 | `ui.js` 有 7 处内联 `background:#0d131a`，非 `!important` 压不过；`--text` 变墨色后会导致"深底深字"完全看不见 | 中长期把内联样式挪进 CSS 类，然后删掉 `!important` |
| `#view` 每 120ms 重建 | 导致 `#view` 内**无法使用**入场/持续动画（会每帧重播） | 可仿照 `renderTabs()` 给 `#view` 加 `if (el.innerHTML === html) return;` 守卫；但这会改变渲染行为，**需单独立项 + 回归测试** |
| `--up-ink` 等三个新变量 | 为纸面可读性引入，与 `--up/--down` 并存 | 已在本文件 §3.2 记录理由 |
| 按钮仍是 CSS 拟物 | 8.2 的图还没生成，当前是纯 CSS 木牌钮（可用的降级态） | 生成后按 §8.0 接入 |
