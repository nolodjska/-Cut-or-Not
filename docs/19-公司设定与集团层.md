```

## 2. 六家公司（公司层）

### 🥕 种植公司 · 稳健经营 — `route A`
- **现实参照**：农户 + 大宗农产品。"蒜你狠 / 豆你玩 / 姜你军 / 葱击波 / 糖高宗"。两个结构性成因：**周期性**（今年赚→明年全种→后年烂市）与**价格信号放大性**（媒体与中间商把短期波动喊成趋势）。
- **一句话**：你没得选，只能种。**量是你的护城河，天是你的老板。**
- **★ 稳定性 4 / 利润率 2 / 上手难度 2**
- **核心循环**：播种 → 盯天气舆情 → 收 → 卖。赚的是**摊薄固定成本**（地块越多，单块灾害风险越被摊平）。
- **独有 UI（A 原型）**：主界面 = **田格子**；顶部一条**天气/舆情带**；每块地直接显示"本次收成预期区间"。
- **独有事件**：🌪 台风（屯粮→涨）· 📢 舆论（"XX 有损健康"→ 暴跌）· 🏭 对手抛售 · 🐖 **猪周期式滞后**（今年涨→AI 全种→明年过剩）。
- **软肋**：**没产业链** ⇒ 永远接受"原料价"，加工利润被制造/贸易吃掉。
- **博弈**：被贸易吃价差，被制造买走原料。

### 📈 贸易公司 · 市场操盘 — `route C`
- **现实参照**：商品贸易商 / 做市商。**1980 亨特兄弟白银逼仓**：杠杆做多 → 对手盘反手 → **交易所九天内五次上调保证金** → 强制去杠杆 → 数周暴跌近 30%。
- **一句话**：你不生产任何东西，你只赌**别人比你急**。
- **★ 稳定性 2 / 利润率 4 / 上手难度 3**
- **核心循环**：低吸高抛 · 挂单吃价差 · 借货看跌；急时"一次买满"打冲击。
- **独有 UI（C 原型）**：主界面 = **盘口 + 资金条**（现金/货值/浮盈/杠杆）合成一屏；挂单画成**深度阶梯**；突出「一键平仓」。
- **独有事件**：⚡ **保证金上调**（复刻亨特兄弟机制，直接砍你的杠杆档）· 🐋 大户逼仓 · 📉 流动性抽干。
- **软肋**：仓储小、地块少 ⇒ 方向错了不能硬扛。
- **博弈**：收割种植/制造的现货；与金融抢资金成本。

### 🕵️ 情报公司 · 信息博弈 — `route D`
- **现实参照**：数据中介 / 商业情报 / 内幕交易 —— **信息不对称本身就是商品**。
- **一句话**：你不知道未来，但你知道**别人还不知道**。
- **★ 稳定性 3 / 利润率 4 / 上手难度 4**
- **核心循环**：提前 6 小时知道事件 → 抢跑建仓/清仓 → 把情报转卖抽成（`intelCommission`）。
- **独有 UI（D 原型）**：主界面 = **线索卡堆 + 时间轴**；每张情报带**置信度**与**倒计时**；时间轴上标出"我现在的位置"与"事件发生点"之间的**领先窗口**。
- **独有事件**：🪤 假情报（准确率不是 100%，这就是风险本身）· 🕳 情报被抢（对家也买了同一条）· 🎯 你放的消息被人反过来利用。
- **软肋**：情报是**消耗品**（过期作废、可能为假）；自身不生产、仓储也小。
- **博弈**：全部人。**唯一靠"时间"赚钱的一条线。**

### 🎭 皮包公司 · 隐身操控 — `route B`
- **现实参照**：离岸空壳 / 壳公司与信披规避。**核心不是"藏钱"，是"藏关系"。**
- **一句话**：你名下的资产越少，你能动的东西越多。
- **★ 稳定性 2 / 利润率 5 / 上手难度 5**
- **核心循环**：注册壳 → 加厚（隐蔽度）→ 开关切换：用壳的名义去吃、去欠、去背锅，真身始终干净。
- **独有 UI（B 原型）**：主界面 = **关系网/账本**：一张表同时显示**名义持股 vs 实际控制**；"隐蔽度"是所有操作都要消耗的资源条；每个动作标注"涨多少关注度"。
- **独有事件**：🔍 监管关注度累积（隐蔽度跌破阈值就掉皮）· 🕵 同行揭底 · 🧾 壳被穿（一次全暴露）。
- **软肋**：隐蔽度是消耗品；做得越大越难藏，暴露后**规模反噬**。
- **博弈**：最像"外挂" ⇒ 需要最硬的护栏。

### 🔨 制造公司 · 加工增值 — `route A`
- **现实参照**：代工/加工制造 + **微笑曲线**（只有产能只能挣组装费，配方与品牌吃两端）。
- **一句话**：种植卖的是"斤"，你卖的是"件"。
- **★ 稳定性 4 / 利润率 5 / 上手难度 3**
- **核心循环**：收原料 → **开一批**（产线占用 + 等待出货）→ 卖成品；品牌把"萝卜干"卖成溢价货。
- **独有 UI（A 原型）**：主界面 = **车间产线图**：每条产线一个带倒计时的槽；配方卡显示「原料成本 / 成品估值 / 一批毛利」（**这三项代码里已有**）。
- **独有事件**：🔧 产线故障 · 🥫 库存腐坏 · 🏷 **品牌暴雷**（一次把溢价打回原形）。
- **软肋**：**开局现金最少**（−1600）还要养产线 ⇒ 前 3 天现金流最紧。
- **博弈**：低价收种植的货、高价卖给贸易。

### 💰 金融公司 · 资本运作 — `route C`
- **现实参照**：银行 / 影子银行。**期限错配**：短借长贷 + 杠杆，行情一逆转就是挤兑。
- **一句话**：你不需要拥有任何东西，你只需要**别人欠你**。
- **★ 稳定性 3 / 利润率 4 / 上手难度 4**
- **核心循环**：低息借 → 高息放 → 收息（`loansOut` / `loanRateMult` / `creditMult`）。
- **独有 UI（C 原型）**：主界面 = **资产负债表**：左"我欠谁"、右"谁欠我"；顶部**到期日历**。
- **独有事件**：💥 挤兑 · 🕳 违约 · 📈 利率突变（5 折优势一夜缩水）。
- **软肋**：杠杆双刃，**破产线近**（660 局里 97 局出局，金融该占相当比例）。
- **博弈**：给所有人供血，也最容易被别人破产拖下水。

## 3. 四套 route UI（"UI 各不相同"的落地方式）

| route | 原型 | 主界面 | 核心动词 | 公司 |
|---|---|---|---|---|
| **A** | 实业 | 田格子 / 车间产线 | 种·收·建·开批 | 种植、制造 |
| **C** | 资金 | 盘口+资金条 / 资产负债表 | 挂单·平仓·放贷·收息 | 贸易、金融 |
| **D** | 情报 | 线索卡堆 + 时间轴 | 买·卖·放消息 | 情报 |
| **B** | 隐身 | 关系网 + 隐蔽度条 | 注册·加厚·开关 | 皮包 |

**同 route 不同公司**：共用骨架、**专属模块不同**——
- 种植的 A vs 制造的 A：制造**多一条产线槽 + 配方卡**；
- 贸易的 C vs 金融的 C：金融**多一张"我欠谁/谁欠我"双栏表 + 到期日历**。

⇒ 既"每家看着都不一样"，又不用写六套框架。

## 4. 集团层（上层 UI）· 玩家 = 金融巨鳄

### 4.1 双层账本
```
个人层（巨鳄）  现金 · 负债 · 持股组合 · 授信 · 声誉
    ↓ 控股 / 参股
公司层（棋子）  资产负债 · 地块 · 作坊 · 品牌 · 隐蔽度   ← 引擎现有的 player 数据就是"公司账"
```
- **控股（>50%）**：并表，公司净资产按比例计入身价，且你能指挥经营；
- **参股（≤50%）**：只有分红 + 股价波动，**进不了它的经营 UI**（只读）。
- ⚠ **口径统一是硬要求**：`07-metrics.js` 现在算的是**单一主体**的净资产。集团层上线前必须先明确它是"这家公司"还是"你的身价"——**两套数字打架是最容易翻车的地方**。

### 4.2 估值：上市 vs 未上市（两套口径）
| | 上市 | 未上市 |
|---|---|---|
| 定价 | **市值 = 股价 × 总股本**（市场说了算，可被砸盘/抬轿） | **估值 = 净资产 × 行业倍数 + 无形资产（品牌/隐蔽度/牌照）** |
| 怎么知道 | 挂牌即公开 | **要请评估师**：付费、**给区间不给点值**、有误差 |
| 流动性 | 高 | 低 ⇒ 卖出要**流动性折价**（DLOM） |
| 玩法钩子 | 你能操纵股价（配合情报放消息 + 贸易砸盘） | **你可以低报资产去抄底收购** |

⭐ "评估师有误差"建议**做成玩法而不是做成精度问题**：同一家公司两次评估给出不同区间，收购谈判就在这个区间上博弈。

### 4.3 股票（集团层交易所）
- **IPO**：把自己的公司上市 → 拿到融资，但**被稀释 + 变成别人的收购目标**（自曝的代价）
- **二级买卖**：赚价差；配合**举牌线**（越过阈值触发公告/要约义务）形成收购节奏
- **增发 / 回购**：稀释对手 vs 护盘
- **操纵链路**（这是六家公司与上层咬合的地方 ✗→✓）：
  **情报公司**放消息 → **贸易公司**砸盘/抬价 → **集团层**在低位吃进 ⇒ 三层的钱在一条链上流动

### 4.4 收购 M&A
- **友好要约** vs **敌意收购**；控制权溢价（现实中常见 20–40%）
- **反收购**（毒丸 / 白衣骑士 / 焦土）作为 AI 的防御手段
- **标的池现成**：那 5 个 NPC 玩家（坤叔 / 祥嫂 / 阿 May …）**就是 5 家可投资、可收购的公司** ⇒ 不用另造池子，直接复用 sim 里的 AI

### 4.5 上层 UI 的信息架构
```
主屏 = 集团总览
 ├─ 顶栏：个人净资产 · 现金 · 授信 · 日历（到期/事件）
 ├─ 控股地图：每家公司一张卡（持股% · 估值or市值 · 健康度 · 【进入经营】）
 ├─ 组合面板：持股管理 / 分红 / 增减持
 ├─ 交易所：挂单买卖 / IPO / 举牌进度
 └─ 并购台：标的扫描 / 估值区间 / 要约 / 反收购预警
点击公司卡 → 进入该公司的 route UI（§3）  ← 上层与下层的唯一接口
```

### 4.6 与现有引擎的接口（都已存在，无需新造）
| 需要 | 现有资产 |
|---|---|
| 可收购的公司 | `s.players` 里的 NPC（坤叔/祥嫂/阿 May） |

## 4.7 治理：合资 · 投票 · 大股东

- **开局不变**：玩家仍然**只开一家公司**（开局选定的），集团层是"之后"的事。
- **可合资办公司** ⇒ 出现**大股东 / 小股东**，公司不再是单人所有。
- **决策走投票**，议题至少包括：卖公司 · 收购公司 · 增发/稀释 · 分红 · 换掌舵人 · 重大投资。
- **三条平局规则（已定）**：
  ```
  超时未表态   ⇒ 自动弃票（弃票＝中性，不帮任何一边）
  票数一半一半 ⇒ 按股份占比决定话语权
  股份也持平   ⇒ 决议终止（僵局，本次决策作废）
  ```
- ⭐ **推论（不用额外写代码就能产生的张力）**：**50/50 合资是天然死锁** ⇒ 玩家会主动去争 **51%**，而不是随便凑一半。建议保留这条。

## 4.8 反白嫆：资产绑公司（核心约束）

- **地 / 作坊 / 仓储 —— 绑定在公司名下**；**卖出公司时它们随公司一起走**（不能先剥离资产、再卖空壳）。
- **没有积累的公司是纯亏**：
  > ✅ **引擎已经支持，不需要新写** —— 真机 tooltip 原文："地租每块 40 G/天，用现金付"。
  > 没有积累的公司每天都在流血 ⇒ "买壳等升值"天然不成立。
- ⚠ **但还有一个洞必须堵**：如果**现金/仓储里的货归个人**，控股股东可以把公司**抽干**（这是最大的白嫆口）。
  👉 建议：**公司现金独立成账**，股东提取必须走**分红决议**（并受留存比例下限约束）。

## 4.9 邮箱：玩家与 NPC 的统一收件箱

- 形态：一个**聊天列表**（会话式），内容 = 合作请求 / 收购通知 / 风声 / **决议通知**。
- ⭐ **投票入口就放在邮箱里**：每封决议邮件带【赞成 / 反对 / 弃权】+ 倒计时
  ⇒ **"超时自动弃票"这条规则自然就实现了**，不用另做一套弹窗。
- **邮箱把三层缝在一起**：风声（情报层 route D）· 收购通知（集团层）· 合作请求（公司层）都是同一种东西。

## 4.10 身价的口径（回答 §4.1 那个硬要求）

> 已定：**身价用于最终结算与合作伙伴，是能力值；公司的资产会有你的权重。**

```
身价 = 个人现金 + Σ( 持股比例 × 该公司的净资产 )        ← 加权并表口径
```
- ⇒ `07-metrics.js` 的输出必须**分层改名**：
  **公司净资产**（公司层，单主体） vs **身价**（集团层，加权并表）—— 两个数都保留，但不能同名。
- 用途：① **最终结算**（比身价） ② **合作伙伴/授信**（NPC 愿不愿意跟你合资、接你的要约，看身价）

## 4.11 按现实细则（本轮拍板：全部按现实；多情况就多情况，补说明文本）

### A. 估值：评估报告制（§4.2 落地）
- 未上市必须**请评估机构出报告**：三法（**资产基础法 / 收益法 / 市场法**）各给一个数 ⇒ 报告天然给**区间**
- 报告有**有效期**（现实 1 年）· 可被对手**质疑并要求复核** · 可选"对外口径"（美化＝风险）
- 上市**不用评估**，市值即定价
- 子代理补充：**误差做成玩法**（两次评估不同区间，收购就在区间上谈），并做**门槛距离条**（"还差 3.2% 可发起决议"）

### B. 持股门槛表（现实依据 → 游戏内效果）
| 门槛 | 现实依据 | 游戏内效果 |
|---|---|---|
| **3%** | 股份公司临时提案 | 可**提交议题** |
| **5%** | 举牌 | **必须公告**（暴露·隐蔽度↓）；每再增减 5% 再公告 |
| **10%** | 提议召开临时股东会 | **可发起决议** ✓ |
| **20%** | 常被认定为"重大影响" | 可**提名董事**（该公司经营 UI 从只读→可看细节）|
| **30%** | **触发要约收购义务** | 必须发出**全面/部分要约**，或被豁免 |
| **50%** | 普通决议过半 | **控股**（普通决议你说了算）|
| **66.7%** | **特别决议** | 修改章程 / 增减资 / 合并分立 / **卖公司** 走这条 |

⇒ **收购不是点一下就成，是一串门槛**；每个节点都要有**说明文本**。

### C. 收购付款方式
现实：现金对价 · **换股（股权置换）** · **分期 + 业绩对赌（earn-out）** · **承债式**（承担标的债务）· **杠杆收购（LBO）** · **借壳上市**
⇒ 游戏内主打三种：**现金** / **换股** / **分期对赌**（对赌未达标 ⇒ 补差价）

### D. 分红：季度盈利结算（§4.8 那个洞已堵）
- **每季度末**按**该季度可分配利润** × 分红比例；比例由**股东会普通决议**定（→ 又回到投票，闭环）
- **只能分现金**：地块 / 作坊 / 仓储里的货**不能分**（绑公司）
  ⇒ ⭐ **这天然堵住了"抽干公司"的洞，不需要再设留存下限**
- 未分配利润**留在公司账上**，按持股比例自动计入身价
  ⇒ ⭐ **分不分红，对你的身价总额等价，只影响流动性** —— 不给玩家留套利空间

### E. 股东上限
**不设强制流通比例**（按现实：可 100% 私有化，全面要约后摘牌退市）

## 4.12 公司现金独立成账（把 §4.8 那个洞堵上）· 本轮按现实补

> **为什么必须先补这一条**：§4.8 已经指出“现金/仓储里的货归个人 ⇒ 控股股东可以把公司抽干”
> 是最大的白嫆口；而 §4.10 把身价定成“个人现金 + Σ(持股% × 公司净资产)”。
> 这两条一旦同时落地，只要**公司现金和个人现金还是同一口锅**，就会出现：
> **卖掉自己公司 30% 的股份 ⇒ 现金进个人账、而并表净资产不打折 ⇒ 身价当场凭空上涨。**
> 这不是平衡问题，是**记账口径问题** —— 所以先补账，再补股份。
> （2026-10-08 实施 NPC 提案通道时实际撞上这条：`consolidated()` 里主控公司走
> `this.nav(p)`、**根本不乘 stake**，`holdings[].stake` 目前未参与身价计算。）

### A. 现实依据
- 公司是**独立法人**：公司账上的钱不是股东的钱。股东想拿钱只有四条路：
  **① 分红（利润分配决议） ② 减资 ③ 清算 ④ 与公司做交易（须公允、关联交易要披露）**。
- 公司法：分配当年税后利润前应提取**法定公积金 10%**（累计达注册资本 50% 可不再提）；**先弥补亏损才能分**。
- ⇒ **“控股股东随手把公司现金转走”在现实里是违法的（抽逃出资 / 侵占公司财产）**，在游戏里就是白嫆。

### B. 游戏内落地（最小改动口径）
| 项 | 现实 | 游戏内 | 需要的字段 |
|---|---|---|---|
| 公司现金 | 独立法人账 | **`holdings[].cash`**（公司现金）与 `players[].cash`（个人现金）分开 | 新增 |
| 股东拿钱 | 只能分红/减资/清算 | **分红走决议**；减资走特别决议；清算是卖公司/破产 | 复用 4.13 |
| 法定公积金 | 先提 10% | **可分配利润 = 本季利润 × (1 − 10%)**；未分配利润留在公司账上、按持股计入身价（⇒ §4.11 D 已定的“分不分红对身体总额等价”依然成立） | 新增 1 个常量 |
| 关联交易 | 须公允 | 个人向公司买货**按市价**（禁“左手换右手”套现） | 已有市价 |
| 注资 | 增资 / 股东借款 | **个人→公司注资**必须存在，否则“公司没钱”会直接死锁 | 新增动作 |

⚠ **迁移口径**：旧存档只有一口锅 ⇒ **首次读档时把 `players[].cash` 全额留在个人账、公司现金置 0**（**不追溯拆分**）。
理由：拆分口径无法从旧数据反推，硬猜会在读档那一瞬凭空创造/消灭价值；置 0 的副作用是“公司一开始没钱”，由上面那条注资通道兜住。

## 4.13 决议与票决（现实细则）· 本轮按现实补

### A. 股东名册（先说清“谁在表决”）
名册 = **所有把该 `corpId` 记在 `holdings` 里的玩家**（含控股方与参股方）。
持仓层已有数据，**不需要新模型**：
```
capTable(corpId) = 遍历 players：holdings.filter(h => h.corpId === corpId)
                   ⇒ [{ pid, stake }]，并自动含“我方 %”
```

### B. 四种权利（门槛 §4.11 B 已列，这里补“怎么用”）
| 门槛 | 现实权利 | 游戏内动作 |
|---|---|---|
| 3% | 临时提案 | 可把一个议题**直接发起表决**（不用等“下次股东会”） |
| 5% | 举牌必须公告 | 越过时**强制公告**：该玩家在其公司上的“外面盯着你的人”↑；**每再增减 5% 再公告** |
| 10% | 提议召开临时股东会 | **可发起决议**（§8 待定③已拍：发起门槛 10%） |
| 20% | 可提名董事 | 该公司从**只读 → 可看细节**（仍进不了经营 UI） |
| 30% | 触发要约收购义务 | **再买就得公开叫价**：对全体股东发要约，不得私下加仓 |
| 50% | 普通决议过半 | 普通决议你说了算 |
| 66.7% | 特别决议 | 修改章程 / 增减资 / 合并分立 / **卖公司** |

### C. 决议生命周期（现实流程 → 游戏时钟）
```
提议（≥10% 发起，写明议题与类型）
  → 送达全体股东（进信匣，票决邮件）
  → 表决期：现实 15 天 ⇒ 游戏内【24 游戏小时】
      （与“合作请求 / 收购通知”的答复期同长 —— 玩家只需记一个数）
  → 计票：一股一票（权重 = 持股%）；
     门槛 = 赞成票占总股本 ≥ 50%（普通）/ ≥ 66.7%（特别）
  → 结果：① 通过 ② 否决 ③ 超时弃票（弃票＝中性，不帮任何一边）
             ④ 僵局（赞成 = 反对且都不达门槛 ⇒ 本次作废）
  → 公告：结果写进流水条；发起方与反对方各收到一封回信
```
**三条平局规则**照 §4.6 已定，不另立。

### D. 议题清单（现实“股东会职权”里最像玩法的那几条）
卖公司 · 收购别家 · 增发/稀释 · 分红比例 · 换掌舵人 · 重大投资（买地/开作坊超阈值）

### E. ⚠ 前置条件（不补账就做不了的）
**“卖公司 / 换掌舵人 / 减资”落在自己公司上时，必须先有 §4.12 的公司现金独立账** ——
否则卖股份 = 印钞（推导见 §4.12 开头）。
⇒ **落地顺序：§4.12 → §4.13（在自己公司上）→ 参股公司上的决议（无前置，可先做）**。

## 4.14 股份转让：现实里那两道“别人先挑”· 本轮按现实补

### A. 定价
| 标的 | 现实定价 | 游戏内 | UI |
|---|---|---|---|
| 上市 | 市价 | 股价 × 股数 | 「行市」 |
| 未上市 | **评估报告区间** | 报告给 [低, 高]；**成交就在区间里谈** | 「估价单」+ 门槛距离条 |
- **控制权溢价**：现实常见 **20–40%**（买到 >50% 时）；游戏内默认 **30%**，可按人格浮动
- **急卖折价（DLOM）**：急于脱手打折；UI 话术「急卖要折价」，§6 已定

### B. 现实里最容易被漏掉、但张力最大的一条：**优先购买权**
> 现实（公司法/章程惯例）：股东向**股东以外的人**转让股权时 ——
> ① 须其他股东**过半数同意**；② 不同意的股东**应当购买**；③ 同等条件下**其他股东有优先购买权（ROFR）**。

⛔ 本项目当前**没有**这条 ⇒ “我出价高就能买走”会成为唯一路径，谈判张力全丢。
✅ 游戏内落地（建议）：
```
NPC 要收你手里某公司的股份时：
  先问其他股东“同样条件你要不要”（自动跑，只在有别的股东时发生）
    ├ 有股东行使 ⇒ 股份转给他（你收到同样的钱；提案方白跑 ⇒ 他会记仇，关系↓）
    └ 无人行使   ⇒ 按原提案成交
  UI 话术：「这价得先问过其他股东 —— 他们可以同价先拿」
```

### C. 现实里另外两道（先记设定，等决议系统落地后再接）
- **随售权（tag-along）**：大股东卖，小股东可要求“同价带上我”
- **领售权（drag-along）**：达到门槛的大股东可强制小股东一起卖
⇒ 这两条与 §4.13 的 66.7% 特别决议天然咬合。

### D. ⚠ 仍然不要碰的
**“卖自己公司的股份”在 §4.12 落地前，一律不实现**（会印钞）。
参股一侧（`corpId !== 主控` 的持仓）**现在已经可以做**：那条路径的并表用
`navSnapshot × control`，是**既有的、被“持仓层 10 条不变量”守着**的口径。

## 4.15 市场分四档 + 种子必须在市场买（按现实补）

> 用户口径（2026-10-08）：“市场品类太少，给我量大管饱。涵盖目前全部公司的实体产品。且种子也是要在市场买的。”

### A. 现实依据
- 现实里农户下单，买的不只是“农产品”：**种子是投入品（生产成本）而不是商品**；
  化肥/农药/农膜/粻食是同一条采购线上东西。
- 农产品分**初级品（未加工）与加工品（成品）**——两者价差就是“加工增值”的来源（对应制造公司）。
- 土地/牌照是**资产市场**，与商品市场不同台（频次低、金额大、要审批）。

### B. 游戏内：市场分四档（同一屏、四个段）
| 档 | 内容 | 现实对应 | 买/卖 |
|---|---|---|---|
| **种子·农资** | 各种作物的种子、肥料、防災品 | 投入品采购 | **只能买**（种子是消耗品） |
| **农产品（原料）** | 全部六家公司的初级产出 | 初级品现货 | 买/卖 |
| **加工品（成品）** | 全部六家公司的制成件 | 成品批发 | 买/卖 |
| **地皮·牌照** | 各类用途地块、经营牌照 | 资产市场（招拍挂） | 买（见 4.16） |

### C. ✅ 必须改的现状口径
- **种子改成“必须买”**：当前播种不真实扣种子。改后：播种消耗**该作物 1 份种子**（库存为 0 就种不了，先市场买）。
  ⇒ 这会把“播种”从“点一下”变成“先备料”——给种植线一个真正的节奏。
- **品类全集**：市场列表 = `s.crops` ∪ `s.products` ∪ `s.inputs`（**自动取全集，不手写清单**）。
  理由：手写清单以后每加一个品种就会漏（本项目已经因“手写清单”踩过坑）。
  ⇒ 每个品种要补两个字段才算“可上市场”：`市场档位` 与 `是否有现货价`。

### D. UI 话术（守 §6 双名制）
| 术语 | 玩家看到 |
|---|---|
| 投入品 / 农资 | “种子·农资” |
| 初级品 / 加工品 | “刚收的” / “做好的” |
| 招拍挂 | “地块放出来了” |

## 4.16 地皮市场（按现实补）

> 用户口径：“市场里面除了商品还有地皮（用来种植，生产制造等等，金融的地是很贵的，科技需求高的地也不便宜等等）。”

### A. 现实依据（为什么地价差这么多）
| 现实规律 | 解释 | 游戏内怎么用 |
|---|---|---|
| **用途管制** | 农地/工业/商服是不同地类，**不能随便改**（农转非要审批） | 买地时就定用途；改用途要走审批（贵 + 耗时） |
| **地均产出决定竞价上限** | 金融/商服地的地均产值高 ⇒ 能承受高地价；工业地地均产值低 | 地价公式里**乘上“这个用途能产出多少”** |
| **出让年限**（中国） | 住宅 70 · 工业 50 · 商服 40 年 | 游戏内：不同用途的**使用年限不同**（到期要续，续要钱） |
| **区位 / 基础设施** | 距市场近、路通、水通 ⇒ 贵 | 区位倍数（城郊/城区/核心） |
| **稀缺 / 人口流入** | 地不是均匀的，指标有限 | 服务器总量有限，买一块少一块 |
| **税费** | 耕地占用税 · 土地增值税 · 契税 | 交易税费（已有手续费口径，按用途差异化） |
| **平整度 / 开发程度** | 净地（三通一平）比毛地贵 | “生熟”价差，熟地可用 |

### B. 游戏内：地皮结构
```
LAND = { id, use, size, district, years, ready, priceBase }
  use      : 农地 · 工业地 · 商服地 · 金融/科技地
  district : 城郊 · 城区 · 核心
  years    : 使用年限（到期续费）
  ready    : 生地（得投钱平整） / 熟地（立即可用）
```
**定价（一层一层乘上去，每一层都看得见）**：
```
地价 = 基准地价 × 用途倍数 × 区位倍数 × 热点系数 × (生地 ? 0.6 : 1) × 稀缺系数
用途倍数（按现实地均产值排序）：农地 1.0 · 工业地 1.8 · 商服地 4.5 · 金融/科技地 9.0
```
⇒ **“金融的地是很贵的”不是写死的数字，是地均产值高的必然结果** ——
玩家能自己算出来为什么贵，而不是“策划说它贵”。

### C. 用途与公司类型的咬合
| 用途 | 接哪个公司的产线 | 现实理由 |
|---|---|---|
| 农地 | 种植（多一块地 = 多一垄产出） | 耕地 |
| 工业地 | 制造（作坊必须建在工业地上） | 工业用地 |
| 商服地 | 贸易（门店/仓库） | 商业服务业用地 |
| 金融/科技地 | 金融、情报（公司总部/机房） | 高附加值用地 |

### D. ⚠ 与现有“买地”的冲突（必须先说清）
引擎现在已经有 `_a_expand`（`10-plot.js:2`；价格是数组 `plotExpandCost:[1200,1800,2600,3500]`，`01-data.js:13` —— **2600 只是第 7 块地的价，不是固定价**）。
> ⚠ 订正（2026-10-08，子代理核出）：本节原写 `_a_buyland`，全仓零命中 —— **那个动作不存在**。
> 教训与本项目其它几次一致：**凭印象引用的标识符必须去代码里核**。
⇒ **不删它**，而是把它的价格改成**读地价公式的最低档地块**（农地·城郊·生地），
保证旧存档/旧测试不破，同时新市场卖的是“有属性差异的地”。

## 4.17 公司资金提取（补 §4.12 的操作层，按现实）

> 用户口径：“资产要分公司可移动资金，可以提取公司资金到自己的账上（要考虑占股，初始肯定是100%）。”

### A. 现实：股东“随手把公司钱转走”是违法的
公司法里这叫**抽逃出资**。合法拿钱只有四条路：

| 现实路径 | 游戏内 | 代价 |
|---|---|---|
| **分红**（利润分配决议） | 走 §4.13 普通决议，按**持股比例**分 | 得有可分配利润（已补亏损、提完法定公积金 10%） |
| **减资** | 走 §4.13 **特别决议**（66.7%） | 要公告；现实中债权人可要求担保 |
| **薪酬** | 掌舵人工资（按日/按季固定） | 有上限（高了股东会否） |
| **股东借款** | **随时可提，但计入个人负债 + 公司应收，到期必还、带息** | 还不上 ⇒ 个人追保（现有破产链路） |

### B. ⭐ 落地口径（直接回答“可提取”）
```
提取公司资金 = 股东借款（默认通道）
  可提取上限 = 公司现金 × 我方持股 × 借款上限系数（默认 0.8）
  初始持股 100% ⇒ 能提走大部分，但
  ⇒ 这笔钱进的是【个人负债】，到期要还本息；还不上就进现有追保链路
```
**为什么不做成“直接搬走不还”**：那正是 §4.12 开头推导的印钞路径；
而且现实里没有这种操作 —— 做成“借款”既满足“能提”，又不破口径。

### C. UI 话术
| 术语 | 玩家看到 |
|---|---|
| 股东借款 / 其他应收款 | “从公司临时拿出来用（要还）” |
| 抽逃出资 | （不出现） |
| 分红决议 | “大家表决要不要分” |
| 减资 | “把投入的钱抽回来一部分” |

## 5. 平衡护栏

1. **隐蔽度 / 关注度**双向条：皮包做大就必须停下来"洗"

## 6. 落地顺序（更新：集团层插到最前）

```
0. 集团层骨架（总览 + 持股 + 估值，先只读不交易）  ← 它定义了下层的"被进入"关系
1. route C 资金/盘口（贸易）    ← 市场+钱庄系统最全，成本最低
2. route A 车间产线（制造）      ← 配方卡已有，加产线槽
