## 一、游戏概述

### 1.1 世界观

这是一个市场法尚不完善的世界。经济生产刚刚开放，规则粗糙、监管缺失、信息不透明。有人埋头种地，有人倒买倒卖，有人贩卖情报，有人用皮包公司暗中操盘。

没有人规定你必须赢，但每个人都会在赛季结束时被记住——以什么方式，由你自己决定。

### 1.2 核心体验

- **放置的轻松**：作物离线生长，每天上线10-20分钟即可
- **市场的紧张**：价格实时波动，同学之间互相博弈
- **斗争的快感**：用经济手段逼仓、做空、收购对手
- **肉鸽的多样性**：每局随机世界、随机天赋、不同Build
- **被记住的满足**：结算不是排名，是叙事颁奖礼

### 1.3 名字含义

"割不割"有两层意思：
- **字面**：作物成熟了，割不割？割了套现，不割等涨价
- **隐喻**：在股市里，你是割别人的人，还是被割的人？

## 二、核心玩法循环

```
开局（随机世界+选公司类型）
  ↓
种地生产（基础现金流，放置节奏）
  ↓
市场交易（发现机会，低买高卖）
  ↓
情报博弈（获取优势，信息差）
  ↓
公司斗争（打压对手，逼仓做空）
  ↓
拍卖会（争夺稀缺资源）
  ↓
垄断/破产/结算（赛季结束）
  ↓
肉鸽重开（保留图鉴，解锁新天赋）
```

## 三、胜负手系统：四种胜利形态

### 设计原则

四种胜利不是并列选项，而是**互相克制、互相成就的生态**。每局只有1个首席胜利者，但人人都有称号。

| 胜利类型 | 胜利形态 | 判定条件 | 称号 | 代表玩家 |
|---------|---------|---------|------|---------|
| A 财富胜利 | 净资产最高 | 净资产≥初始资产3倍 | 农业大亨 | 稳健经营者 |
| B 生存胜利 | 最后活着 | 存活且负债率<30% | 不倒翁 | 隐忍防守者 |
| C 霸权胜利 | 垄断市场 | 控制某作物≥60%流通量 | 市场霸主 | 激进操盘手 |
| D 综合胜利 | 积分最高 | 种地/交易/收购/拍卖四项总分第一 | 全能商人 | 多面手 |

### 判定优先级

1. 优先判定C（垄断），达成即触发，立即结算
2. 若无人达成C，比较A/B/D的达成度，最高者成为首席
3. 其他达成者获得次级称号
4. 叙事提名不限人数，每人最多1-2个

### 克制关系

| 路径 | 克制 | 被克制 |
|------|------|--------|
| A 财富 | 克制B（有钱就能扛过危机） | 被C克制（垄断者可以定价，稀释你的资产） |
| B 生存 | 克制C（不参与斗争，垄断者打不到你） | 被A克制（资产碾压，收购你） |
| C 垄断 | 克制A（控制市场，让资产贬值） | 被B克制（你不卖，他耗得起） |
| D 综合 | 不克制任何人 | 被所有人克制（因为分散，没有专精） |

## 四、公司类型系统

### 4.1 玩家扮演什么

**Demo阶段**：玩家选一种公司类型开局，通过收购扩展。
**完整版**：玩家是"资本家"，可注册多家公司，自由组合。

### 4.2 公司类型与胜利路径对应

| 公司类型 | 核心业务 | 天然倾向 | 玩法风格 |
|---------|---------|---------|---------|
| 种植公司 | 种地生产 | A 财富胜利 | 稳健经营 |
| 贸易公司 | 低买高卖 | C 霸权胜利 | 市场操盘 |
| 情报公司 | 买卖消息 | D 综合胜利 | 信息博弈 |
| 皮包公司 | 伪装、代持、洗钱 | B 生存胜利 | 隐身操控 |
| 制造公司 | 加工增值 | A/D 混合 | 产业链整合 |
| 金融公司 | 借贷、投资 | A/C 混合 | 资本运作 |

### 4.3 重点公司设计

#### 情报贩子公司

**核心玩法**：信息就是商品。

**业务模式**：
- 收集情报：通过"线人网络"获取市场事件、对手动向
- 贩卖情报：卖给需要的玩家/NPC
- 制造假情报：散布虚假消息，影响市场价格
- 情报订阅：收取月费，定期提供情报

**Demo设计**：
- 情报分三级：公开消息（免费）、内幕消息（付费）、绝密消息（拍卖）
- 假情报可被识破，识破后信誉下降
- 情报只提供概率优势，不提供确定性结果

#### 皮包公司

**核心玩法**：隐身、代持、隔离风险。

**业务模式**：
- 代持资产：帮别人持有土地、库存，收取管理费
- 洗钱：把做空获利等收入洗白
- 隔离风险：用皮包公司承接债务，破产不波及母公司
- 伪装收购：悄悄收购对手股权，不被发现

**Demo设计**：
- 皮包公司有"隐蔽度"属性，隐蔽度越高，越难被识破
- 被识破后，资产会被冻结
- 皮包公司不能直接产生收益，只能作为工具
- 可注册多个，但每个都有维护成本

#### 制造公司

**核心玩法**：加工增值，产业链整合。

**业务模式**：
- 收购原料：从种植公司买作物
- 加工产品：把作物变成高价值商品（如辣椒→辣酱）
- 品牌溢价：建立品牌后，产品售价更高
- 纵向整合：收购上下游，控制全产业链

**Demo设计**：
- 加工需要时间（对应放置玩法）
- 加工品有独立市场，价格波动
- 品牌需要时间积累，但一旦建立，溢价稳定
- 加工利润高但周期长，适合放置玩家

### 4.4 公司互动关系

```
种植公司 → 卖原料 → 制造公司
制造公司 → 卖产品 → 贸易公司
贸易公司 → 卖情报 → 情报公司
情报公司 → 卖消息 → 所有公司
皮包公司 → 代持 → 所有公司
金融公司 → 借贷 → 所有公司
```

## 五、市场系统

### 5.1 作物设计

| 作物 | 生长周期 | 垄断门槛 | 设计意图 |
|------|---------|---------|---------|
| 萝卜 | 2小时 | 60%流通量 | 入门作物，容易垄断但利润低 |
| 辣椒 | 8小时 | 55%流通量 | 中期作物，斗争主战场 |
| 人参 | 24小时 | 50%流通量 | 高端作物，垄断难度大但收益高 |

### 5.2 价格波动机制

- **供需模型**：价格 = 基础价 × (1 + 需求系数 - 供应系数)
- **随机事件**：每天生成市场事件（干旱、丰收、网红带货等）
- **玩家影响**：大额交易会影响价格，这是斗争的基础
- **离线保护**：离线时价格波动减半

### 5.3 市场事件示例

| 事件 | 效果 | 战略价值 |
|------|------|---------|
| 干旱预警 | 所有作物减产，价格预期上涨 | 囤货机会 |
| 丰收季 | 供应增加，价格下跌 | 做空机会 |
| 网红带货 | 某作物需求暴涨 | 提前布局 |
| 政策变动 | 某作物税收变化 | 影响成本 |
| 瘟疫 | 某作物减产50% | 逼仓机会 |

### 5.4 核心操作链条（你的例子）

**逼仓—破产—收购**完整流程：

1. **情报获取**：发现辣椒价格连续上涨，通过情报市场确认内幕
2. **布局**：买入催熟剂，大量种植辣椒，悄悄囤积现货
3. **抛售打压**：突然以极低价格抛售，市场价格暴跌
4. **对手困境**：对手库存积压，现金流断裂，债务到期
5. **收购**：以极低价格收购其土地、仓库、公司
6. **恢复价格**：垄断后恢复价格，获利

## 六、拍卖系统

### 6.1 拍卖标的类型

| 类型 | 例子 | 战略价值 |
|------|------|---------|
| 稀缺资源 | 高产地、稀有种子 | 长期优势 |
| 破产资产 | 对手的土地、仓库 | 扩张 |
| 政策特权 | "本月免税""独家出口权" | 规则优势 |
| 情报 | 下季度市场走势预测 | 信息优势 |
| 债务包 | 别人的坏账 | 斗争工具 |

### 6.2 拍卖机制

- **暗标+明标结合**：先暗标出价，再公开竞价
- **非现金资产出价**：可用囤积的作物抵价
- **允许狙击**：最后一秒出价
- **允许串通**：私下约定不互相抬价（但可能被背叛）

### 6.3 拍卖的心理战

- **假装感兴趣**：引诱对手高价拿下，消耗其现金
- **故意抬价**：让对手以过高价格成交，然后做空其公司
- **联合围标**：和其他同学围堵对手，事后分赃

## 七、肉鸽系统

### 7.1 每局随机的世界种子

开局生成随机世界，包含：
- **作物池**：本局有哪些作物
- **市场规则**：本局有哪些漏洞可用（如允许裸卖空、无涨跌停）
- **NPC公司**：3-5个AI对手，各有性格（激进/保守/阴险）
- **随机事件池**：本局会触发哪些天灾、政策、商机

### 7.2 局内成长（天赋树）

每局通过种地、交易、收购获得"资本点数"，解锁天赋：

**种植系**：
- 催熟剂：作物瞬间成熟（一次性）
- 杂交：解锁稀有作物
- 抗灾：天灾时减产减半

**市场系**：
- 内幕消息：提前知道市场事件
- 舆论操纵：影响某作物价格
- 裸卖空：允许无货做空

**斗争系**：
- 债务陷阱：借钱给对手时利息翻倍
- 挖角：挖走对手员工
- 狙击：拍卖最后一秒出价

### 7.3 每局随机3选1

每次升级时，从当前可用的天赋中随机抽3个，选1个。保证每局Build不同。

### 7.4 失败与重开

- **破产**：本局结束，保留部分图鉴解锁
- **被收购**：可"复仇开局"，带少量遗产重新开始
- **通关**：垄断本局所有作物市场

## 八、结算系统：叙事颁奖礼

### 8.1 核心理念

结算不是审判，是叙事。玩家不是在争名次，而是在创造一段被记录的历史。

### 8.2 结算层次结构

**第一层：首席胜利者（1人）**
- 达成C（垄断）或结算时最接近垄断
- 全场C位，最高荣誉

**第二层：胜利路径达成者（2-4人）**
- A财富、B生存、D综合的达成者
- 各自获得称号

**第三层：叙事提名（不限人数）**
- 每人最多获得1-2个提名
- 提名不冲突，可多人获得同一提名

### 8.3 叙事提名类型

| 提名 | 判定依据 | 颁奖词示例 |
|------|---------|-----------|
| 最佳市场搅屎棍 | 市场波动率贡献前3，且自身收益≤0 | "你的存在让市场哀嚎。在你的操盘下，没有赢家。这是你愿意看到的局面吗？" |
| 经济命运共同体 | 带动其他公司营收增长总量第1 | "你的种种策略，让半数公司经济腾飞。你做出了一个繁荣的都市。你是英雄。" |
| 隐形操盘手 | 通过皮包公司影响市场，但从未公开露面 | "没有人知道你是谁。但市场记得你的每一次出手。" |
| 泡沫制造机 | 制造了最大价格泡沫，且在破裂前离场 | "你吹起了泡沫，又在破裂前离场。你是天才还是骗子？" |
| 最悲情破产者 | 破产时资产最接近垄断条件 | "你差一点就赢了。差一点。" |
| 定海神针 | 全程未参与斗争，资产稳健增长 | "你是这个疯狂市场里唯一清醒的人。" |
| 最佳情报商 | 情报交易次数最多，且准确率最高 | "你卖的不是消息，是命运。" |
| 产业链之王 | 纵向整合度最高 | "你控制了从种子到餐桌的每一个环节。" |
| 韭菜收割机 | 从其他玩家交易中获利最多 | "你收割了所有人。但下一个被收割的，会不会是你？" |
| 城市奠基人 | 累计生产/加工/交易总量最高 | "你建起了这座城市。虽然没人记得你的名字。" |

### 8.4 偏安玩家的完整结算体验

假设一个玩家全程只种萝卜，不参与斗争，最后也没垄断。

**结算画面**：
> "你偏安一隅，但你的每一次播种、每一次出售，都在改变这个市场的命运。"
>
> 你的提名：
> - 定海神针：全程未参与斗争，资产稳健增长
> - 经济命运共同体：你的萝卜支撑了3家制造公司的生产
> - 最佳市场搅屎棍：你的一次抛售导致辣椒市场崩盘，间接导致某公司破产

## 九、时间结构

### 9.1 完整赛季（4-6周）

| 阶段 | 时间 | 玩法 | 节奏 |
|------|------|------|------|
| 拓荒期 | 第1周 | 种地积累原始资本，市场平静 | 轻松，每天上线收菜 |
| 分化期 | 第2周 | 玩家开始分化，第一次拍卖会 | 开始有博弈 |
| 斗争期 | 第3周 | 公司斗争白热化，第二次拍卖会 | 紧张，需多次上线 |
| 决战期 | 第4周 | 季末大拍卖，最后的收购与反收购 | 高潮，集中在线 |

**放置感体现**：第1周和第2周前半段可轻松放置；第3-4周才需密集操作。

### 9.2 Demo短局（3天）

| 时间 | 事件 | 玩法 |
|------|------|------|
| 第1天 | 拓荒+分化 | 种植、初步交易 |
| 第2天 | 斗争开始 | 第一次拍卖会，NPC动手 |
| 第3天 | 决战+结算 | 垄断判定，叙事颁奖 |

### 9.3 放置玩法落地

- **作物生长**：短周期（2-4小时）适合高频玩家，长周期（24-72小时）适合放置玩家
- **离线事件**：作物继续生长，市场价格波动减半，NPC可能动手但有预警
- **自动化设施**：自动浇水、自动收割、条件单、委托经营
- **每日低保任务**：上线3分钟收菜补种，获得活跃点兑换稀有道具

验证"种地→市场操作→打压对手→收购"这个链条是否好玩。

### 10.2 Demo配置

## 十一、技术实现建议

### 11.1 技术栈

- **前端**：微信小程序 / H5
- **后端**：Node.js + Redis（实时价格）+ 定时任务（作物生长）
- **价格引擎**：供需模型 + 随机事件 + 玩家交易影响
- **数据**：轻量数据库，重点存持仓、订单、事件日志

### 11.2 核心数据追踪

每个玩家的行为日志：

| 数据项 | 用途 |
|--------|------|
| 每笔交易的时间、价格、数量 | 计算波动率贡献 |
| 每次合作的对手方、金额 | 计算带动增长 |
| 每家公司破产时的债权人 | 计算"影响破产" |
| 皮包公司注册/注销记录 | 判定隐形操盘手 |
| 情报买卖记录 | 判定最佳情报商 |
| 资产曲线 | 判定定海神针、最悲情破产者 |

**关键**：Demo阶段就要开始记录这些数据，哪怕暂时不用来发奖。

## 十二、设计原则与避坑

### 12.1 核心原则

1. **种地不能太赚**：否则没人玩市场。种地是保底，市场是暴富
2. **斗争不能太狠**：要有复仇机制，被坑的人能翻盘
3. **信息不能太透明**：否则没有博弈空间
4. **拍卖不能太频繁**：一周一次，保持稀缺感
5. **肉鸽不能太随机**：随机的是机会，不是结果
6. **结算要让每个人被看见**：偏安玩家也有提名

### 12.2 需要避开的坑

- **别做成真赌博**：不引入充值、提现，纯娱乐
- **别太复杂**：股票知识要隐形，玩家先觉得好玩，再发现"原来这是K线"
- **别让肝帝碾压**：放置游戏核心是时间换收益，但要有上限（仓储容量、地块数量）
- **社交要轻**：同学之间可以互坑，但要有复仇机制，避免关系破裂

### 12.3 独特卖点

| 维度 | 《割不割》 | 其他经济游戏 |
|-------|-----------|-------------|
| 公司类型 | 多公司类型对应多胜利路径 | 通常选一个行业深耕 |
| 时间结构 | 肉鸽赛季+放置日常分层 | 要么纯肉鸽，要么纯放置 |
| 结算系统 | 叙事提名，人人被记住 | 排行榜或资产排名 |
| 偏安玩家 | 有专门提名认可 | 通常被视为"没赢" |
| 斗争手段 | 逼仓、做空、收购、皮包公司 | 通常只有买卖 |

## 十三、一句话总结

**《割不割》= 种地放置的轻松 + 肉鸽重开的多样 + 多公司类型的克制生态 + 叙事提名的结算系统。**

- 种地是入场券，市场是绞肉机，拍卖是屠宰场
- 四种胜利路径互相克制，没有最强玩法
- 每局只有1个首席胜利者，但人人都有称号
- 偏安一隅的玩家也会被记住
- 你的每一次播种、每一次出售，都在改变这个市场的命运
