# 《割不割》Demo

种地是入场券，市场是绞肉机，拍卖是屠宰场，结算是一场颁奖礼。

**当前状态：可玩，内容比较完整。** 单文件 H5 + 美术资产，双击就能玩，不需要服务器、不需要联网、不需要安装任何东西。

```
直接玩   →  双击 dist/割不割-demo.html（单文件，自带 emoji 兜底）
完整体验 →  连同 dist/assets/ 一起拷走（有美术资源时自动启用插画）
手机上看 →  用浏览器打开 dist/preview.html（390×844 手机视口预览）
本机试玩 →  cd dist && node ../tools/serve.cjs（或任意静态服务器），浏览器开 http://127.0.0.1:8901/demo.html
```

- 6 家公司、3 种作物、3 种加工品、7 个页面、3 个 NPC 对手
- 3 个游戏天 = 标准局约 10 分钟（可切 2 分钟极速局 / 3 天放置局）
- 自动存档 + 继续上局 + 图鉴 + 复仇开局

## 二、怎么跑

```bash
# 1) 跑一局（最简单）
双击 dist/割不割-demo.html

# 2) 改了源码后重新打包
node tools/build.mjs

# 3) 引擎平衡验证：40 个种子 × 9 种打法 = 360 局
node tools/sim.cjs 40 8
#    第二个参数 = 1 游戏小时对应几真实秒（1.6 极速 / 8 标准 / 3600 放置）
#    输出：各打法净资产倍数分布、垄断率、破产率、提名触发率，以及
#         可复现性 / 存档往返 / 不变量 / 拍卖全链路 四类断言

# 4) UI 冒烟（不需要浏览器）
node tools/ui-smoke.cjs

# 5) 文案红线检查
node tools/lint-copy.cjs

# 6) 美术资产：生图原图 → 游戏用 WebP（需要 Pillow）
python tools/prepare-assets.py
```

URL 参数（用于分享某个具体局面或截图）：
`dist/割不割-demo.html?auto=1&corp=trade&plant=chili&warm=2400&view=market&speed=0`
- `auto=1` 跳过开局弹层直接进局
- `corp` = `grow` / `trade` / `intel` / `shell`
- `plant` = 开局自动播种该作物
- `warm` = 先推进 N 个**游戏分钟**（1440 = 1 天）
- `view` = `farm` / `market` / `intel` / `bank` / `auction` / `end`
- `speed` = 默认 `0`（暂停，方便截图）

## 四、四条设计原则的落地验证

设计原则（来自原案 §12.1）不是口号，每一条都对应仓库里的一个可验证断言：

| 原则 | 怎么验证 | 实测结果 |
|---|---|---|
| 种地不能太赚 | `sim.cjs` 里 "farmer" 打法 vs "trader" 打法 | 纯种地 1.61 倍 / 交易流 1.30 倍 —— ⚠️ 见下 |
| 斗争不能太狠 | 单次价格战的最大伤害被阀门夹住 | 价格带 0.70~1.45，硬顶 1.75~2.20 ✅ |
| 信息不能太透明 | 内幕情报 80% 准确、可造假、有冷却 | 情报流 1.73 倍，与贸易流齐平（不是印钞机）✅ |
| 结算要让每个人被看见 | 360 局统计提名触发率 | 10 个提名全部会触发，形成「4 参与 + 2 中档 + 4 稀有」✅ |
| 别让肝帝碾压 | 地租 40 G/天/块 + 地块上限 8 | 扩地有持续成本，占着不种会亏 ✅ |
| 不是真赌博 | 无充值、无提现、无真钱出口 + 文案红线自动检查 | `lint-copy.cjs` 零命中 ✅ |

## 五、已知限制

1. **只有单机**。3 个 NPC 对手，没有真人。社交博弈（联合围标、私下约定）无法在 Demo 里验证。
2. **美术只做了 6 张**。作物图标 / 颁奖背景 / 分享底图 / 1 张事件图；
   其余资产（公司徽章、10 枚奖章、其余 6 张事件图、App 图标）还没生，
   提示词已经写好在 `docs/10` 里，跑一遍 `gen.mjs` 即可（约 $3~5）。缺图的地方现在用 emoji 兜底。
3. **拍卖只拍 1 个标的**（规则变异下最多 3 个），且没有「非现金资产抵价」和「临时同盟」——
   这两项设计在 03 分支文档里有完整方案，Demo 未实现。
4. **制造公司与金融公司没做**。
5. **微信小程序做不了**：游戏类目需要版号（6-12 个月）。当前只发 H5。
6. **平衡基于脚本实测**，不是真人实测。脚本比人蠢，所以真人手里数字会更好看（尤其 A 门槛）。
